## 三条硬规则

1. **一个子任务没验收，不开始下一个。** 0.5 人日的任务拖成 2 人日，通常是因为上一个没真正做完。
2. **产物列写的是文件路径，不是“模块”这种抽象名词。** 建不出来就说明这个子任务还没想清楚。
3. **实现要点里的命名和 `app/` 现有代码保持一致。** T02 的 `DeviceStatus`、T12 的 `RuleEngine` 已经在仓库里，别另起一套。
