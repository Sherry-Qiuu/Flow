## 1. 目标

立起一条能跑起来的本地服务：HTTP + WebSocket + 事件总线 + 配置 + 健康检查，其余所有模块都挂在这条骨架上。

## 2. 需求依据

- **SR-17** — 屏幕显示表情 + 文字信息（P43）——UI 与后端靠一条实时通道通信。

## 3. 输入 / 输出

**输入**

- T01 的系统环境
- T02 的 HAL 接口（可先用 mock）

**输出（可交付物）**

- FastAPI 应用骨架（app/main.py、路由、WS）
- EventBus 与统一消息协议
- config.yaml 加载与 .env 密钥隔离
- 各模块可用的脚手架与示例

## 4. 工作内容

- [ ] FastAPI + uvicorn 单进程；/healthz 返回版本、启动时间、子系统状态
- [ ] WebSocket /ws：连接即下发 state.sync 全量快照；客户端断线指数退避重连
- [ ] 事件总线：bus.subscribe(topic, handler) / bus.publish(topic, payload)，asyncio 实现，支持通配 *
- [ ] 消息协议统一：{type, payload, seq, ts}，Pydantic 校验，非法消息回 error 不退出
- [ ] topic 常量集中在 bus/topics.py，禁止字符串硬编码
- [ ] 配置：config.yaml + 环境变量覆盖，API Key 只放 .env（不入 git、不入库）
- [ ] 生命周期：启动顺序 db → hal → scheduler → ws，关闭逆序，优雅退出
- [ ] 结构化日志：JSON lines，带 trace_id，便于串联一次对话的全过程
- [ ] REST 约定：/api/{domain}/{action}，统一错误结构与 HTTP 状态码

## 5. 接口契约

```
# WebSocket 消息（服务端 → 客户端）
{"type": "state.sync", "payload": {...}, "seq": 1, "ts": "..."}
{"type": "ui.phase",   "payload": {"phase": "idle|listening|thinking|plan_review|executing|celebrating|resting",
                                   "channel": "clock|tasks|plan|focus|reminder|music"}}
{"type": "assistant.say", "payload": {"text": "...", "emotion": "happy"}}
{"type": "task.created",  "payload": {"tasks": [...]}}
{"type": "plan.draft",    "payload": {"plan_id": "...", "items": [...]}}
{"type": "reminder.fired","payload": {"id": "...", "title": "...", "kind": "timer"}}
{"type": "phone.changed", "payload": {"present": true, "charging": false}}
{"type": "reward.event",  "payload": {"kind": "step_done", "points": 5}}
{"type": "error",         "payload": {"code": "...", "message": "..."}}

# WebSocket 消息（客户端 → 服务端）
{"type": "user.intent", "payload": {"text": "...", "source": "voice|gesture|ui"}}
{"type": "ui.action",   "payload": {"action": "plan.confirm", "plan_id": "..."}}
{"type": "focus.control","payload": {"action": "start|pause|skip|finish"}}
```

## 6. 验收标准（Definition of Done）

- [ ] curl /healthz 返回 200，包含版本号、启动时间、db/hal/scheduler 状态
- [ ] 前端连上 WS 后 10 秒内收到 state.sync
- [ ] 向 /ws 发送非法 JSON，服务不退出且回一条 error
- [ ] Ctrl+C 优雅退出，日志无异常堆栈、无残留子进程

## 7. 风险与降级

- uvicorn 多 worker 会导致事件总线和调度器重复执行 → 强制单 worker

## 8. 提示

> 事件总线的 topic 清单要在开工第一天就定死，否则后面模块各发各的消息，联调会非常痛苦。
