# T07 · 语音输出与表情联动

> 工作流：**单通道交互**（CHN）・优先级 **P0**・规模 **M**（2 人日）

| 字段 | 内容 |

| 任务 ID | `T07` |

## 1. 目标

机器人的“说话”是语音 + 表情 + 屏幕文字三合一的人格化输出，而不是一个音箱在念稿。

## 2. 需求依据

- **SR-17** — 屏幕：显示表情 + 文字信息（P43）
- **SR-09** — 先给完成反馈与庆祝（P24）——声音是庆祝的重要一半

## 3. 输入 / 输出

**输入**

- T02 AudioOut
- T05 FaceExpression 组件
- T06 的打断信号

**输出（可交付物）**

- TTS 服务（音色可切换、可缓存）
- 播报队列与优先级
- 文字 + 表情 + 语音的同步呈现

## 4. 工作内容

- [ ] TTS 引擎：edge-tts（zh-CN-XiaoxiaoNeural 等神经网络音色，免费），可配置音色
- [ ] 缓存：常用语句（提醒、确认、鼓励）预生成 wav 存本地，命中 ≤ 300ms 出声
- [ ] 播报队列：去重、可打断、按优先级排序（提醒 > 对话 > 闲聊 > 装饰音）
- [ ] 节奏：长句按标点切分，句间 150ms 停顿，避免连读过快
- [ ] 表情联动：每条语音携带 emotion 标记 → 同步驱动 FaceExpression，说完保持 1 秒再回 neutral
- [ ] 静音模式：可配置夜间时段（默认 22:00–07:00）只走屏幕文字 + 极轻提示音
- [ ] 失败降级：TTS 服务不可用 → 退回屏幕文字 + 提示音，不阻塞业务流程
- [ ] 音量：整体音量可调，庆祝音效音量不得超过播报音量

## 5. 接口契约

```
say(text: str, emotion: str = "neutral", priority: str = "normal") -> None
# 事件：assistant.say {text, emotion}
# 队列规则：高优先级抢占，同级 FIFO，重复文本 5 秒内丢弃
```

## 6. 验收标准（Definition of Done）

- [ ] 一句 15 字中文从调用到出声 ≤ 1.5 秒；缓存命中 ≤ 300ms
- [ ] 同一句话不会被重复播报（5 秒去重窗口）
- [ ] 静音模式下提醒仍然生效（屏幕文字 + 轻提示音）
- [ ] 播报被打断后队列正确清空，不出现半句残留
- [ ] 表情与语音情绪一致（人工抽查 10 句全对）

## 7. 风险与降级

- edge-tts 依赖网络 → 必须保留离线 TTS（piper）或预生成音频包
- 树莓派音频输出爆音 → 调整 ALSA buffer，或加 softvol 限幅

## 8. 提示

> 把 50 句高频话术全部预生成 wav 打进镜像，离线演示时体验几乎无损。
