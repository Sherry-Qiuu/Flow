## 1. 目标

知道“手机在不在架子上、有没有在充电”——这是手机管控与专注状态的前置信号。

## 2. 需求依据

- **SR-19** — 支架：放手机 + 感应 + 充电 + 文件拍照传输（P42）

## 3. 输入 / 输出

**输入**

- T02 HAL 传感器接口
- 微动开关 / ToF / INA219 任一组合

**输出（可交付物）**

- 在位状态机
- phone.changed 事件
- phone_sessions 记录

## 4. 工作内容

- [ ] 传感方案（择一或组合）：微动开关（最可靠）、ToF 距离、重量传感器；充电判定用 INA219 电流阈值（> 100mA 视为充电中）
- [ ] 状态机：absent → placed → charging → removed，连续 3 次采样一致才切换（去抖）
- [ ] 事件：phone.changed {present, charging, current_ma, at}，通过总线广播
- [ ] 记录：phone_sessions 写入放上/取下时间，供 T21/T18 使用
- [ ] UI：待机页角标显示在架 / 充电状态，不主动打扰
- [ ] 降级：无传感器时提供语音替代“我拿手机了 / 我放回去了”，不报错

## 7. 实现要点

```
PhoneStand 去抖状态机（已在 hal/real 实现）：

    absent ──present×3──> placed ──charging──> charging
      ↑                      │                   │
      └────────removed───────┴───────────────────┘

阈值：连续 3 次采样一致才切换；轮询默认 100ms
事件：bus.publish("phone.changed", {present, charging, current_ma, distance_mm})
```

## 8. 验收标准（Definition of Done）

- [ ] 放上/取下后 2 秒内状态更新
- [ ] 充电识别准确率 ≥ 95%（真机测试 20 次）
- [ ] 拔掉传感器后以手动方式替代且服务不报错
- [ ] 连续抖动（放上又拿起）不会产生大量虚假会话记录

## 9. 风险与降级

- 电流检测受充电器协议影响 → 用阈值 + 变化率双重判定
- 手机壳厚导致 ToF 误判 → 优先微动开关

## 10. 提示

> 半天工的任务，但它是后面所有手机功能的地基，别拖到最后。
