## 1. 目标

拿手机前先约法三章，到点提醒归位——把注意力外流变成“有借有还”。

## 2. 需求依据

- **SR-07** — 用户要使用手机进行资料查阅/玩的时候都可以向机器人提出来，机器人问需要多长时间，到时间提醒用户放回手机（P22）
- **SR-13** — 在拿取手机做任何事情之前设定手机使用时长，到达设定时间之后提醒手机归位（P31–P32）

## 3. 输入 / 输出

**输入**

- T20 在位与充电状态
- T15 提醒调度
- T07 语音播报

**输出（可交付物）**

- 使用契约创建流程（用途 → 时长 → 计时）
- 倒计时屏显与到点提醒
- 归位检测与准时率记录

## 4. 工作内容

- [ ] 创建流程：用户说“我要用手机查资料” → 问用途（学习/休闲）→ 问时长（学习默认 15 分钟、休闲默认 10 分钟，可语音改）→ 开始计时
- [ ] 屏幕：极简倒计时（大字剩余时间 + 用途），不显示其他内容
- [ ] 到点策略：先轻提醒一次；30 秒未归位再加一句更明确的提醒；仍未归位记录一次“未按时归还”
- [ ] 归还检测：T20 的 phone.changed 自动结束计时；也可语音“放回去了”
- [ ] 用途差异：学习用途可申请延长一次（+5 分钟），休闲用途不可延长
- [ ] 数据：phone_sessions 记录用途、计划时长、实际时长、是否准时，供 T18 画像
- [ ] 隐私：只记录时长与用途，绝不记录手机上做了什么
- [ ] 恢复：断电重启后按已过去的时间恢复计时或直接触发提醒

## 5. 子任务拆解

每项 ≤0.5 人日，可单独勾选验收。做完一项就在 `产物` 那一列把文件建出来。

| 子任务 | 名称 | 产物 | 完成判据 | 人日 |
|---|---|---|---|---|
| `T21.1` | 契约创建流程 | `app/phone/contract.py` | 用途→时长两问完成；3 轮对话内结束；学习 15 / 休闲 10 默认值 | 0.5 |
| `T21.2` | 倒计时与屏显 | `ui/src/pages/PhoneTimer + focus 通道` | 极简大字剩余时间；不显示其它干扰信息 | 0.5 |
| `T21.3` | 到点提醒与归位检测 | `app/phone/contract.py` | 到点 3 秒内提醒；放回支架自动结束；30 秒未归位升级语气 | 0.5 |
| `T21.4` | 用途差异与超时记录 | `app/phone/contract.py` | 学习可延长一次 +5 分钟；休闲不可；未按时归还正确入库 | 0.5 |

**小计 2.00 人日**

## 6. 接口契约

```
# 事件：phone.session.started / phone.session.ended / phone.session.overdue
# REST：POST /api/phone/session {"purpose": "study|leisure", "minutes": 15}
#       POST /api/phone/session/{id}/end
#       POST /api/phone/session/{id}/extend {"minutes": 5}
```

## 7. 实现要点

```
PhoneSession(id, user_id, purpose, planned_minutes, started_at,
             ended_at, returned_on_time, extended_count)

状态机：

    idle ──"我要用手机"──> ask_purpose ──> ask_duration ──> running
    running ──到点──> remind(1) ──30s──> remind(2) ──> overdue
    running ──phone.present──> ended(returned_on_time=True)

延长：purpose=="study" 且 extended_count==0 才允许 +5 分钟
```

## 8. 验收标准（Definition of Done）

- [ ] 语音创建一次使用契约 ≤ 10 秒完成（3 轮对话以内）
- [ ] 到点后 3 秒内开始提醒
- [ ] 手机放回支架后自动结束计时，无需额外操作
- [ ] 超时未归还被正确记录并在周统计中体现
- [ ] 断电重启后计时正确恢复
- [ ] 休闲用途无法申请延长

## 9. 风险与降级

- 用户把手机放上去但不充电 → 以“在位”判定为准，充电只做辅助
- 提醒太凶导致反感 → 语气分级要克制，第一次一定轻
