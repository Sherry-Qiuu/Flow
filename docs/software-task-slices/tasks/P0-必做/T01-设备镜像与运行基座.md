# T01 · 设备镜像与运行基座

> 工作流：**平台底座**（PLT）・优先级 **P0**・规模 **M**（2 人日）

## 1. 目标

把树莓派从“裸机”变成开机即用的一体机：系统、网络、显示、自启动、日志全部固化，用户接触不到操作系统。

## 2. 需求依据

- **SR-19** — 外观 15×15×5cm、自带 14×14 屏幕、另一面手机支架（P37–P39）——意味着软件必须开机直接进产品界面，没有桌面。

## 3. 输入 / 输出

**输入**

- 树莓派 5（4GB+）或 4B、A2 级 SD 卡、电源
- 屏幕、摄像头、麦克风、扬声器、支架套件

**输出（可交付物）**

- 可重复烧录的系统镜像（或 install.sh 一键脚本）
- systemd 服务组：flow-hal / flow-backend / flow-ui
- 诊断导出命令 flow-diag

## 4. 工作内容

- [ ] 系统选型：Raspberry Pi OS Lite 64-bit (Bookworm)，关闭桌面环境与无用服务（蓝牙按需）
- [ ] 首次启动配置：WiFi 凭据、时区 Asia/Shanghai、中文 locale、中文字体（Noto Sans CJK，防方块字）
- [ ] 显示固定：HDMI/DSI 输出锁定目标分辨率（如 720×720），关闭 overscan
- [ ] Kiosk：Chromium --kiosk 指向 http://127.0.0.1:8000，隐藏鼠标指针，屏蔽右键与 Ctrl+W 等快捷键
- [ ] systemd 单元：开机顺序 hal → backend → ui，任一失败自动重启（Restart=always，限流）
- [ ] 日志：journald + 按天轮转保留 7 天；flow-diag 打包 journal + 配置 + 版本 + 传感器状态
- [ ] 时间：chrony 校时，断网时用 RTC 或上次已知时间兜底
- [ ] 可选加固：overlayfs 只读根分区，防止断电损坏 SD 卡

## 5. 接口契约

```
flow-hal.service   →  python -m hal.daemon
flow-backend.service → uvicorn app.main:app --host 127.0.0.1 --port 8000
flow-ui.service    →  chromium --kiosk http://127.0.0.1:8000

/opt/flow/
  app/        后端代码
  ui/         前端构建产物
  data/       flow.db、inbox/、backup/
  config.yaml 设备配置
  version.json
```

## 6. 验收标准（Definition of Done）

- [ ] 断电重启后 90 秒内自动进入产品界面，无需任何人工操作
- [ ] 断网状态下界面可正常启动，并显示“离线模式”标识
- [ ] journalctl -u flow-backend 能看到完整启动日志，无字体缺失警告
- [ ] 中文在目标屏幕上渲染正确，无方块、无截断
- [ ] 屏幕分辨率与其他模块的 720×720 设计画布一致

## 7. 风险与降级

- 屏幕 DSI 驱动兼容性差 → 优先选 HDMI 屏，或提前验证 dtoverlay
- SD 卡掉电损坏 → 用 A2 卡 + 每日备份 + overlayfs

## 8. 提示

> 先用普通 HDMI 显示器把整条链路跑通，再接真实屏幕，能省一半调试时间。
