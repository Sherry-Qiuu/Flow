# T09 · 手势与在场感知交互（已取消）

> 状态：**取消，不执行**。产品已改为 720×720 触屏，手势输入不再属于产品范围。

## 为什么取消

- 屏幕本身支持触控，直接点按比挥手更可控，也不受光照、距离和佩戴物影响。
- 手势传感器增加 BOM、接线、开孔和误触发调参成本，收益不足。
- 手机在位/充电（T20/T21）与手势无关，继续保留。

## 已清理内容

- `app/gesture/`（detector / presence / service / CLI）已删除。
- `hal` 的 Gesture 契约、MockGesture、RealGesture、PAJ7620 驱动已删除。
- runtime 的 gesture 子系统、`gesture.detected` 总线主题、gesture 配置已删除。
- `paj7620` 依赖与安装脚本段落已删除。
- T05 UI 的手势提示改为触屏按钮。
- T01/T05 硬件文档不再包含 PAJ7620 接线、I2C 0x73 和手势验收。

## 替代方案

- 触屏：Idle 的任务/专注/计划，PlanReview 的确认/再改改，Executing 的完成/跳过/卡住/延长。
- 语音：与触屏共用同一套 `/api/intent`、`/api/plan/...`、`/api/focus/control` 后端动作。
- 手机在位/充电仍由 T20 的 `phone.changed` 和 T21 契约处理。

本任务卡不再有验收项；保留 ID 仅用于历史引用。
