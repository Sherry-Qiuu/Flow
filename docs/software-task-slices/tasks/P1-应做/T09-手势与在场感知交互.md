# T09 · 手势与在场感知交互

> 工作流：**单通道交互**（CHN）・优先级 **P1**・规模 **M**（1.5 人日）

| 字段 | 内容 |
|---|---|
| 任务 ID | `T09` |
| 工作流 | 单通道交互（`CHN`） |
| 优先级 | P1 |
| 规模 | M / 1.5 人日 |
| 前置依赖 | `T02`、`T04` |
| 需协同 | `T05`、`T20` |
| 建议角色 | 嵌入式 |

## 1. 目标

没有触屏，靠近、挥手、放手机都要被感知并转成操作——手势是触屏的替代品，不是装饰。

## 2. 需求依据

- **SR-18** — 语音交互 + 手势交互：代替触屏（P43）
- **SR-19** — 支架：放手机 + 感应（P42）

## 3. 输入 / 输出

**输入**

- T02 HAL 传感器接口（ToF / 接近 / 微动）
- T04 意图路由

**输出（可交付物）**

- GestureDetector：距离与手势事件
- 手势 → Intent 映射表
- 校准与防误触参数

## 4. 工作内容

- [ ] 硬件：VL53L0X（ToF 测距，精度足够）、可选 APDS9960（方向手势）、微动开关（手机在位）
- [ ] 手势集要少而准：approach（< 60cm 唤醒屏幕）、wave（左右挥手 = 确认/下一句）、leave（> 3m 持续 60s 进待机）、phone_place / phone_take
- [ ] 防抖：滑动窗口 + 冷却 1.5 秒，同一手势 1.5 秒内只触发一次
- [ ] 校准：开机自检记录基线距离；桌面与手持场景分别标定阈值
- [ ] 手势 → 与语音等价的 Intent，走 T04 同一条路由，不单独造一套逻辑
- [ ] 降级：传感器缺失时自动隐藏相关功能，不报错

## 5. 接口契约

```
# 事件：gesture.detected {type: "approach|wave|leave|phone_place|phone_take", confidence: 0.9}
# 阈值放在 config.yaml：
gesture:
  approach_cm: 60
  leave_cm: 300
  leave_hold_s: 60
  cooldown_s: 1.5
```

## 6. 验收标准（Definition of Done）

- [ ] 挥手确认在静置环境下误触发 < 5 次/小时
- [ ] 靠近 1 秒内点亮屏幕
- [ ] 放上手机 2 秒内识别为 phone_place
- [ ] 离散 3 米 60 秒后自动进入待机（可关闭）
- [ ] 拔掉传感器后功能自动隐藏，服务无报错

## 7. 风险与降级

- ToF 在强光下漂移 → 用滑动中位数滤波；必要时换成微动开关更可靠
- 用户摆手势习惯差异大 → 只做“有/无”判断，不做精细手势识别

## 8. 提示

> “靠近唤醒”是最容易被感知到的小功能，成本一天，演示效果却很好，优先做它。
