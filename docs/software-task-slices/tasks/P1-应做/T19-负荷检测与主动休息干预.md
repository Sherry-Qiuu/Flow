# T19 · 负荷检测与主动休息干预

> 工作流：**情绪与激励**（EMO）・优先级 **P1**・规模 **M**（2 人日）

| 任务 ID | `T19` |
| 工作流 | 情绪与激励（`EMO`） |
| 优先级 | P1 |
| 规模 | M / 2 人日 |

## 1. 目标

机器人主动发现“你已经很累了”，而不只是被动等人喊停。

## 2. 需求依据

- **SR-11** — 检测连续高强度任务后主动建议休息（P29）
- **SR-14** — 在外出运动 / 做更丰富的休息的时候提醒（P33）

## 3. 输入 / 输出

**输入**

- T14 专注会话数据
- T15 提醒调度
- T18 分心数据（可选）

**输出（可交付物）**

- 负荷信号采集与打分
- 三级干预与休息引导卡
- 反打扰策略

## 4. 工作内容

- [ ] 信号：连续专注时长、切换次数、跳过率、卡住次数、当前时段（深夜）、分心频率
- [ ] 规则：连续 90 分钟无休息 → 建议 10 分钟；连续 3 天晚间工作 → 建议外出/运动
- [ ] 干预分级：轻（一句话提醒）→ 中（暂停计时 + 休息引导卡）→ 重（建议今天到此为止）
- [ ] 休息内容库：拉伸、走动、喝水、远眺、外出，都带计时
- [ ] 反打扰：用户说“知道了”后 N 小时（默认 2 小时）内不重复同类提醒
- [ ] 阈值可配置并可学习个人节律（简单统计：用户在哪个时段效率/完成率最高）
- [ ] 与 T15 的分工：T15 管“几点响”，T19 管“为什么现在该响”

## 6. 验收标准（Definition of Done）

- [ ] 连续专注 90 分钟后必定触发一次休息建议
- [ ] 用户拒绝后 2 小时内不重复同类打扰
- [ ] 休息卡有计时，结束后能准确回到原步骤
- [ ] 阈值在设置里可调，改完立即生效
- [ ] 深夜时段（23:00 后）阈值更保守

## 7. 风险与降级

- 打扰本身就是负担 → 每一次主动干预都必须给用户“知道了，别烦我”的出口
- 阈值拍脑袋 → 先定规则版，收集两周真实数据再调

## 8. 提示

> 这一块与 T16 的情绪目标一致：所有主动干预的语气都是“关心”，不是“管理”。
