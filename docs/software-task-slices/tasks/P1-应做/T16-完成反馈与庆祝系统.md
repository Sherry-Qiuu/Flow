# T16 · 完成反馈与庆祝系统

## 1. 目标

每次完成都有即时的、不廉价的正反馈——对抗“做了也没用”的无力感。

## 2. 需求依据

- **SR-09** — 完成反馈设计：庆祝每个任务完成，用即时正反馈对抗“做了也没用”的无力感（P24）

## 3. 输入 / 输出

**输入**

- T14 完成事件
- T05 动效体系
- T07 音效通道

**输出（可交付物）**

- 三级反馈（小步 / 整任务 / 里程碑）
- 文案库与去重
- 夜间与连续完成的抑制策略

## 4. 工作内容

- [ ] 反馈分级：小步（1–2 秒动效 + 轻音效）、整任务（3 秒庆祝 + 语音肯定 + 养成奖励）、里程碑（连击、清零积压、周目标达成）
- [ ] 文案库：至少 20 条，随机且不连续重复；禁用否定式与比较式（“终于做完了” ✗，“你比上周快” ✗）
- [ ] 动效：表情放大、粒子、进度环填满；音效音量必须低于播报音量
- [ ] 抑制：深夜降级为静音动效；连续完成 5 个以上改为合并庆祝，避免刷屏替代成就感
- [ ] 数据：写入 reward_events，供 T17 成长与 T27 周报使用
- [ ] 开关：设置里可关闭动效 / 音效，功能逻辑不受影响

## 6. 验收标准（Definition of Done）

- [ ] 完成小步有可感知但不超过 2 秒的反馈
- [ ] 文案 20 条以上且不会连续重复同一条
- [ ] 深夜模式下无突兀音效
- [ ] 关闭反馈开关后，完成流程仍然正常推进
- [ ] 连续完成 8 步时出现合并庆祝而不是 8 次刷屏

## 7. 风险与降级

- 过度庆祝削弱真实感 → 分级是关键，小步一定不要大张旗鼓

## 8. 提示

> 收集一次真实用户测试的反馈录音，比再改十轮动效参数都有用。
