| 铁氧体隔磁片 | **没有替代品**。没隔磁片就**不要开无线充** —— 直接砍掉这个功能 |
| D10×3 磁铁 | 用两颗 D3×3 叠起来（磁力翻倍），或改用机械卡扣 |
| M2.5×4+10 铜柱 | 用两个 4+6 铜柱对拧成 12mm，或用 M2.5 螺母堆叠 |
| 外壳 | 纸板 + 热熔胶做原型（能验功能，不能演示）；或买现成塑料盒改造 |
