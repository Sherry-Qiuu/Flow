## 2. 原理（2 分钟）

你买的模块是 **5W Qi 发射端（TX）**：

```
  5V 输入 ──> [驱动电路] ──> [发射线圈] ──电磁场──> 手机里的接收线圈
                                    │
                              [铁氧体隔磁片]  ← 只让磁场往"前"走
                                    │
                                 外壳背板
```

**隔磁片的作用**：磁场是对称的，不挡就有一半往后跑，打到后面的**电池、铝壳、螺丝**上，在那里产生涡流发热。**没有隔磁片 = 用 5W 的功率去烤你的电池。**

清单里**没配隔磁片**，这是必须先补的（¥5，见 H01）。

## 4. 通电前的四条安全规则

🔴 **规则 1：线圈直径范围内、背面 5mm 内，绝对不能有金属。**
包括：电池本体、铝壳、螺丝、铜柱、磁铁。隔磁片就是干这个的，**没贴隔磁片不许通电**。

🔴 **规则 2：不要空载长时间通电。**
发射端找不到接收端时会持续以最大功率搜索，线圈会明显发烫。测试时**每次通电不超过 30 秒**。

🔴 **规则 3：发热超过 60°C（手摸明显烫但能坚持 3 秒以上）立刻断电。**
正常工作是微温到温热。

🔴 **规则 4：不要给装了金属壳 / 里面有金属贴片的手机充电。**
会剧烈发热。

## 5. 供电接入（15 分钟）

### 5.1 模块需要多少电

5W 输出 + 转换损耗，输入大约 **5V / 1.2–1.5A**。

**这很关键**：你的降压模块只有 5A，树莓派峰值就可能吃掉 3A 以上。**无线充最好单独走一路供电**，不要和树莓派抢同一个 5A。

### 5.2 两种接法

**接法 A（推荐，独立供电）**

买一个 **12V→5V 2A 的小降压模块**（约 ¥5），单独给无线充供电。这样：
- 树莓派供电稳定，不会因为手机充电而重启
- 无线充可以单独开关（省电、保续航）

**接法 B（省钱，共用 5V 轨）**

从降压模块的 5V 输出并联出来，加一个**拨动开关**控制通断。

> 无论哪种，都必须加开关。否则电池模式下手机一直充电，续航从 2.5 小时掉到 1.2 小时。

### 5.3 接线

```
[5V 输出] ──┬── [拨动开关] ──> 无线充模块 VIN(+)
            │
[GND]  ─────┴────────────────> 无线充模块 GND
```

**上电前用万用表量：**
- 模块 VIN 对 GND 必须是 **5.0–5.2V**
- **不能超过 5.5V**（超了会烧模块）

## 6. 装配：线圈怎么放（20 分钟）

这是整个模块最讲究的一步。层次关系（从外到内）：

```
      手机背面（接收线圈在里面）
           ▲  间距 2–6mm
   ┌───────────────────┐
   │   外壳支架背板     │  ← 塑料/亚克力，厚 1.5mm
   ├───────────────────┤
   │   发射线圈         │  ← 线圈朝外（朝手机）
   ├───────────────────┤
   │   铁氧体隔磁片     │  ← 关键！在线圈和内部之间
   ├───────────────────┤
   │   塑料隔板（1mm）  │
   ├───────────────────┤
   │   电池 / 树莓派    │  ← 必须离开 5mm 以上
   └───────────────────┘
```

### 6.1 关键尺寸

| 参数 | 要求 | 不满足的后果 |
|---|---|---|
| 线圈到手机的间距 | **2–6 mm** | 太远不充电（>8mm 基本无效） |
| 线圈直径 vs 手机接收线圈 | 中心对齐误差 < **10mm** | 偏移会掉功率甚至不充 |
| 线圈背面到电池的距离 | **≥ 5 mm**（有隔磁片也要留） | 发热 |
| 隔磁片尺寸 | **≥ 线圈外径** | 小了磁场还是往后漏 |

### 6.2 装配步骤

1. **先不要装进壳里**。在桌面上平放：隔磁片 → 线圈（正面朝上）→ 手机。
2. 手机放上去，看是否进入充电（屏幕显示充电图标）。
3. 前后移动找**最佳位置**，用铅笔标记。
4. 在标记位置用 **VHB 胶**把隔磁片贴到支架背板内侧。
5. 隔磁片上再用 VHB 贴线圈（线圈正面朝外）。
6. 线圈引线用胶带固定在背板上，**不要悬空**（会晃、会断）。
7. 装进壳后再测一次。

### 6.3 手机怎么"对准"

靠 **D10×3mm 磁铁**做定位：
- 手机背面贴一片（保护壳外面或壳内）
- 支架对应位置埋一片（极性要相吸）
- 磁铁位置**必须在线圈中心 30mm 以外**，否则会干扰磁场 / 磁铁被加热

> 磁铁位置错误是"充不上电"最常见的第二个原因（第一个是没隔磁片）。

## 7. 检测"手机是否在充电"（15 分钟）

产品需要知道手机到底有没有在充，才能做"使用时长契约"。三种方法，从易到难：

### 方法 A：霍尔传感器（你已经有，推荐）

手机上贴磁铁，支架里装 A3144（H04 已做）。**手机在位 = 磁铁靠近 = 霍尔导通**。

这就是清单里那两颗 A3144 的用途。简单、可靠、不依赖充电状态。

### 方法 B：测电流（更准确，但要加器件）

在 5V 线上串一个 **INA219 电流传感器**（约 ¥8，清单里没有）。

```python
# 伪代码
if ina219.current_ma > 150:
    charging = True     # 有电流 = 手机在充
```

优点：能区分"手机放上但没在充"（比如手机不支持 Qi）。
缺点：要加器件、要写 I2C 代码。

### 方法 C：两者结合（最终方案）

```python
present  = hall.present          # 霍尔：手机在不在架上
charging = ina219.current_ma > 150   # 电流：有没有在充

if present and charging:
    state = "手机在架，正在充电"
elif present and not charging:
    state = "手机在架，但没在充电（检查对齐/手机壳）"
elif not present:
    state = "手机不在架"
```

**建议**：先用方法 A 把功能跑通，方法 B 作为 P1 增强。

## 9. 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| 完全不充电 | 没装隔磁片，模块进保护 | 补隔磁片 |
| 完全不充电 | 距离 > 8mm | 减薄背板，或把线圈往前挪 |
| 完全不充电 | 手机壳太厚（>3mm） | 摘壳测试 |
| 完全不充电 | 手机不支持 Qi | 换手机测试 |
| 完全不充电 | 模块供电不足 | 量 VIN 电压、查线粗 |
| 断断续续 | 线圈没固定，位置在漂 | 用 VHB 粘牢 |
| 断断续续 | 磁铁离线圈太近干扰 | 磁铁移远到 30mm 外 |
| 充电很慢 | 功率只有 5W，正常 | 接受它（这个模块就是 5W） |
| 线圈或背板发烫 | 磁场漏到后方金属 | **立刻断电**，加大/补隔磁片 |
| 电池发烫 | 磁场打到了电池 | **立刻断电**，加大隔磁片距离 |
| 树莓派莫名重启 | 无线充抢电导致 5V 掉压 | 改独立供电 |

## 10. 产品层面的取舍（重要）

无线充电很酷，但代价是：

| | 有无线充 | 没有无线充 |
|---|---|---|
| 演示效果 | 手机放上就充，很有说服力 | 少一个亮点 |
| 续航 | **1.2 小时** | 2.5 小时 |
| 安全风险 | 有（发热） | 无 |
| 装配难度 | 高（隔磁片 + 对准） | 低 |

**建议**：

- 演示时展示，演示完关掉开关。
- 产品说明里明确写"无线充电仅在有外接电源时使用"。
- 如果时间紧，**这个模块可以直接砍掉** —— 它是 P1，不影响主线。
