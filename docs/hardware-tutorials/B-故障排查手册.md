# 附录 B · 故障排查手册

> 出问题先查这里，**不要先拆机**。80% 的故障在这一页就能定位。

---

## 0. 五分钟急救流程

遇到"不工作"，**按这五步走，别跳**：

```
第 1 步  断电，等 10 秒，重新上电        → 30% 的问题消失
第 2 步  检查所有插头有没有松            → 再解决 40%
第 3 步  python3 self_test.py 看哪项红   → 定位到具体模块
第 4 步  只保留那个模块，其它全拔掉      → 排除干扰/抢电
第 5 步  单模块还不work → 查本节对应表格
```

> **一条铁律**：任何"动过的线"都要怀疑。刚装完壳后出的问题，99% 是结构压到了什么。

## 1. 树莓派开不了机

| 现象 | 概率 | 原因 | 处理 |
|---|---|---|---|
| 红灯亮、绿灯完全不闪 | 高 | SD 卡没插好 / 卡坏了 | 重新插，或用 Imager 重写 |
| 红灯不亮 | 高 | 没供电 / 线断 | 换官方 PD 电源测 |
| 绿灯闪两下就停 | 中 | 系统镜像损坏 | 重写 SD 卡 |
| 反复重启 | 中 | 供电不足（电池/降压模块撑不住） | 换 PD 电源验证，查 H03 |
| 有电但屏幕不亮 | 高 | HDMI 接错口 | 换 HDMI0 / HDMI1 |
| 屏幕亮但黑屏 | 中 | 分辨率不匹配 | 换标准显示器试 |
| 开机后立刻关机 | 低 | 散热没装，温度保护 | 检查风扇排线 |

## 2. 电源相关

| 现象 | 原因 | 处理 |
|---|---|---|
| 屏幕右上角出现**闪电图标** | 欠压 | 换粗的 C-to-C 线；查 `vcgencmd get_throttled` |
| `get_throttled` 返回 `0x50005` | 当前正在欠压 | 立刻降负载，检查电池电压 |
| 用电池时频繁重启 | 降压模块过流保护 | 减少同时负载（关无线充、屏幕单独供电） |
| USB 设备时有时无 | 没加 `usb_max_current_enable=1` | 加进 `/boot/firmware/config.txt` |
| 电池几十分钟就没电 | 无线充开着 / 电池老化 | 关无线充；测电池容量 |
| 关机后又自己开机 | Pi 5 软关机后仍带电 | 加拨动开关，或关机后断电 |
| 电池发烫 / 鼓包 | 过充 / 短路 / 劣质 BMS | **立刻断电，移到室外，报废** |
| 充电时设备很烫 | 边充边用 | 充电时必须关机或待机 |

## 3. 屏幕与触摸

| 现象 | 原因 | 处理 |
|---|---|---|
| 完全黑屏 | 视频线没插 / 接错 HDMI 口 | 换口，换线 |
| 黑屏但树莓派正常 | 屏幕没供电 | 单独给屏 5V |
| 画面有雪花/条纹 | 线太长或接触不良 | 换短线（<30cm） |
| 画面颜色异常 | HDMI 模式不匹配 | `raspi-config` 调整 |
| 画面倒置/旋转 | 显示方向配置 | 设置里旋转 180° |
| 触摸没反应 | 触摸线没接 / 接错口 | 试 Mini / Micro / Type-C 三种线 |
| 触摸位置偏移 | 校准没做 / 旋转后没重校 | `xinput` 校准 |
| 触摸乱跳 | 屏幕电源不稳 | 单独供电，加大电容 |
| 屏幕有压痕/亮斑 | 装配压到面板 | 无法修复，换屏 |
| 装壳后屏幕不亮 | 排线被压断 | 拆开检查 |

## 4. 摄像头

| 现象 | 原因 | 处理 |
|---|---|---|
| `No cameras available` | 排线没插到底 | 断电重插，确认卡扣压紧 |
| `No cameras available` | 排线插反 | 断电翻面重插 |
| `No cameras available` | 插错接口（接了 DISP） | 换到 **CAM0** |
| `No cameras available` | 用了 12P 那根线 | **必须用 22 针 Pi 5 排线** |
| 照片全黑 | 镜头盖 / 遮挡 / 快门太短 | 检查镜头，加大 `--shutter` |
| 照片全白 | 过曝 | 减小 `--shutter` |
| 照片模糊 | 距离 < 10cm（定焦限制） | 移到 25–35cm |
| 颜色偏黄/偏蓝 | 白平衡 | 调 `--awbgains` 或 `--awb auto` |
| `failed to acquire camera` | 别的进程占用了 | `pkill rpicam` |
| 拍照时重启 | 供电不足 | 查 H03 |

## 5. I2C / 手势传感器

| 现象 | 原因 | 处理 |
|---|---|---|
| `i2cdetect` 全空 | SDA/SCL 接反 | 对调（接反不烧，只是不通） |
| `i2cdetect` 全空 | 没接 GND | 补上 |
| `i2cdetect` 全空 | 没启用 I2C | `sudo raspi-config nonint do_i2c 0` |
| `i2cdetect` 全空 | 传感器没供电 | 量 VCC 对 GND = 3.3V |
| 有 0x73 但读 ID 是 0xFF | 线太长 / 时序 | 杜邦线缩到 10cm 内 |
| `Errno 121` 远端 I/O 错误 | 接触不良 | 换线、重插 |
| 识别不到手势 | 距离太远（>25cm） | 移到 10–20cm |
| 识别不到手势 | 手太快/太慢 | 正常速度挥 |
| 误触发多 | 强光干扰 | 避开直射，加遮光 |
| 装壳后失效 | 窗口被挡住 | 扩大窗口，去掉遮挡 |
| 库装不上 | pip 环境问题 | `pip3 install paj7620 --break-system-packages` |

## 6. 按钮 / 霍尔

| 现象 | 原因 | 处理 |
|---|---|---|
| 按钮没反应 | 接到 5V 了 | 量 GPIO17 对 GND：按下应 0V |
| 按钮按一次触发多次 | 机械抖动 | `bounce_time=0.1` |
| 按钮一直显示按下 | 没开内部上拉 | 代码 `pull_up=True` |
| 4 脚按钮没反应 | 选错脚对 | 通断档找导通的一对 |
| 一按就重启 | 接到 5V/GND 短路 | **立刻断电**，核对接线 |
| 霍尔一直是 1 | 忘接 10kΩ 上拉 | 补上 |
| 霍尔一直是 1（有上拉） | 磁铁极性反 | 翻面 |
| 霍尔一直是 1 | 距离太远 | 靠近到 5–15mm |
| 霍尔一直是 0 | VCC/GND 接反 | 量供电 |
| 霍尔读数乱跳 | 没上拉 + 线太长 | 补 10k，缩短线 |

## 7. 振动马达

| 现象 | 原因 | 处理 |
|---|---|---|
| 完全不震 | 三极管腿序错 | 万用表重测 E/B/C |
| 完全不震 | 三极管插错面包板行 | 三腿分三排 |
| 完全不震 | 马达线断了（1027 线极细） | 测通断，重新焊/接 |
| 一直震不停 | 基极悬空 | 确认 1kΩ 接好 |
| 震动很弱 | 占空比低 / 电压不足 | 提高 PWM；可改 5V 供电（重算电阻） |
| **一震动就重启** | **没有续流二极管** | **立刻断电，补 1N4148** |
| 三极管发烫 | 基极电流不足未饱和 | 1kΩ 换 470Ω |
| 震一下就停 | 马达被外壳卡住 | 松开固定 |

## 8. 无线充电

| 现象 | 原因 | 处理 |
|---|---|---|
| 完全不充 | 没装隔磁片，模块保护 | 补隔磁片 |
| 完全不充 | 距离 > 8mm | 减薄背板 |
| 完全不充 | 手机壳太厚 | 摘壳测 |
| 完全不充 | 手机不支持 Qi | 换手机验证 |
| 完全不充 | 供电不足 | 量 VIN = 5.0–5.2V |
| 断断续续 | 线圈没固定 | VHB 粘牢 |
| 断断续续 | 磁铁离线圈太近 | 磁铁移到 30mm 外 |
| 充电很慢 | 模块只有 5W | 正常，接受 |
| 线圈/背板发烫 | 磁场漏到后方金属 | **断电**，加大隔磁片 |
| 电池发烫 | 磁场打到电池 | **立刻断电**，拉开距离 |
| 开无线充就重启 | 抢电导致 5V 掉压 | 改独立供电 |

## 9. 结构

| 现象 | 原因 | 处理 |
|---|---|---|
| 装壳后系统异常 | 铜柱太矮短路 | 换 M2.5×4+10 |
| 支架开合卡顿 | 两铰链不同轴 | 重新定位 |
| 支架合不上 | 磁铁太小 | 换 D10×3 |
| 硅胶包边翘边 | 壁厚不匹配 | 打磨或加胶 |
| 壳内异响 | 螺丝/线头掉进去了 | **立刻拆开取出**（会短路） |
| 整机发烫 | 通风不足 | 开散热孔 |
| 屏被压出亮斑 | 装配受力 | 重装，减小压紧力 |

## 10. 什么时候该停下来别修了

出现下面任一情况，**停止折腾，直接换件**：

- 电池鼓包、有异味 → 报废，别修
- 树莓派闻到糊味 / 某个 GPIO 永久无反应 → 换板
- 屏幕出现不可逆亮斑/裂纹 → 换屏
- 三极管、传感器接反烧过 → 换新件（烧过的器件不可靠）
- 排线金手指磨损发黑 → 换排线

> 修理烧过的元件是学生项目最大的时间黑洞。**一块 ¥40 的模块不值得花 3 小时救。**
