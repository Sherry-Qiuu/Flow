## 这套教程怎么用

这不是"看看就懂"的读物，是一张**施工图**。每一节都以"你手上多了一个能工作的模块"结束，并且有一张验证表和一张排错表。

- **零基础可以看**：每个术语第一次出现时都会解释，不需要任何前置知识。
- **不要跳着做**：H03（电源）没过，后面所有节都可能把板子烧掉。
- **每节结束填记录表**：填完才算过，没填等于没做。

## 三条可以并行的路线

硬件不是只能一个人从头做到尾。按下面拆，**3 个人可以同时推进**：

| 路线 | 谁做 | 顺序 |
|---|---|---|
| **A · 电源与主控** | 1 人 | H01 → H02 → H03 → H08 |
| **B · 传感器与小件** | 1 人 | H01 → H02（先做一个最小系统）→ H04 → H05 → H06 → H07 |
| **C · 结构与装配** | 1 人 | H01 → 设计/打印外壳 → H09 → H10 |

> 关键：B 路线的人**不需要等 A 完成**。H02 用主办方给的 PD 电源就能跑通树莓派，传感器全部可以在桌面上单独验证。

没有这 4 样，**不要开始**：

| 工具 | 为什么必须有 | 大概价钱 |
|---|---|---|
| **万用表**（带蜂鸣通断档） | 接线前测通断、上电前测短路、测电池电压 —— 唯一能救你板子的工具 | ¥40–80 |
| 十字螺丝刀一套（含 PH0/PH1） | M2 螺丝和 M2.5 铜柱 | ¥15 |
| 剪线钳 / 剥线钳 | 剪杜邦线、剥电池线 | ¥20 |
| 绝缘胶带 or 热缩管 | 防短路，**这一步不做真的会烧板** | ¥10 |

可选但强烈建议：镊子、扎带、热熔胶枪、放大镜（看引脚丝印）。

## 五条安全红线（现在就记住）

1. **锂电池正负极接反 = 炸。** 每次接线前，万用表量一遍极性。
2. **上电前必测短路。** 万用表打蜂鸣档，量 5V 和 GND，响就是短路，别上电。
3. **树莓派 GPIO 只吃 3.3V。** 5V 信号直接进 GPIO 会烧掉引脚，甚至烧掉整片 SoC。
4. **马达、继电器这类感性负载，绝不直连 GPIO。** 必须过三极管 + 续流二极管。
5. **无线充电模块通电时，线圈 5cm 内不能有金属和电池。** 会感应加热，严重的会鼓包起火。

详见 [D · 安全手册与红线](D-安全手册与红线.md)。

## 和软件部分怎么衔接

| 硬件教程产出 | 交给哪个软件任务 |
|---|---|
| 按钮 / 霍尔 / 马达 / 手势 / 摄像头的可运行验证代码 | `T02` HAL 与开机自检 |
| 手机在位检测的判定逻辑 | `T20` 手机在位与充电感知 |
| 7 寸屏的分辨率、触摸接口类型 | `T05` 屏幕 UI 框架 |
| 摄像头取帧参数（分辨率、对焦距离） | `T11` 任务捕获：拍照导入 |
| 整机功耗与续航数据 | `T03` / `T29` 稳定性与降级测试 |
