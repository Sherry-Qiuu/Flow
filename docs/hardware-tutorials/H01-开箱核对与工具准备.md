## 4. 通电前的 3 分钟物理检查

在碰任何电之前，把每个器件拿在手上看一遍：

- [ ] 有没有**烧焦味**、有没有元件歪了、有没有焊点拉丝（尤其买来的模块）
- [ ] 杜邦线两端是不是**都压紧了**（用手轻拉，掉了就换一根）
- [ ] 排线金手指**干不干净**（不要用橡皮擦，会掉屑）
- [ ] 电池外壳有没有鼓包（鼓包 = 立刻报废，别用）
- [ ] 摄像头镜头有没有划痕（用气吹，不要用纸擦）

## 5. 六个必须今天就处理的坑

清单里这几项**买了但用不了，或者压根没买**。现在下单，后面才不会停工。

### ⚠️ 坑 1：MGN7C 导轨滑块 —— 建议退货

`MGN7C` 是**滑块**，必须配 `MGN7` 导轨才能滑动。清单里只有滑块没有导轨，**单独完全没用途**。

- 处理：能退就退（¥4.5）；不想麻烦就留着当垫块。

### ⚠️ 坑 2：强磁铁 D3×3mm —— 吸不住手机，务必换

直径 3mm 的磁铁磁力太小，隔着手机壳/背板基本没吸力，支架合上会自己弹开。

- 处理：买 **D10×3mm 圆片磁铁 4–8 颗**（约 ¥6），退货原来的 50 颗。
- 用法：手机上贴一片、支架对应位置埋一片，靠磁吸定位。

### ⚠️ 坑 3：铜柱 M2.5×4+6 —— 高度不够

`4+6` 表示螺纹 4mm、**架空只有 6mm**。7 寸屏背板 + 树莓派背面元件需要至少 **10mm** 净空，否则 Pi 的元件会顶到屏背板短路。

- 处理：换 **M2.5×4+10**（架空 10mm），买 4–8 个（约 ¥2）。

### 🔴 坑 4：无线充电缺铁氧体隔磁片 —— 不补会发烫

Qi 发射线圈背面如果没有隔磁片，磁场会穿透到电池和金属结构件上，产生**涡流发热**，轻则效率暴跌、重则把电池烤鼓包。

- 处理：必买 **40–50mm 铁氧体隔磁片**（约 ¥5）。

### 🔴 坑 5：缺 USB-C 公对公短线

降压模块输出是 Type-C **母座**，树莓派 5 也是 Type-C **母座**。两个母座之间必须有 **C-to-C 公对公短线**（20–30cm），清单里没有。

- 处理：必买（约 ¥6）。**注意买"数据+充电"线，别买只有充电的残线**。

### 🔴 坑 6：缺 DC5.5×2.1 公头带线

清单里只有 DC **母座**（装在机身上的充电口），没有把电池接到降压模块/充电座的 **公头线**。

- 处理：必买（约 ¥3），选"免焊带线"款。

### 另外 4 项"可能缺"的东西

| 物品 | 为什么可能要 | 判断方法 |
|---|---|---|
| **microSD 卡 32GB A2** | 主办方只给了读卡器，可能没卡 | 打开 Pi 5 套件盒子看有没有卡；没有就买（约 ¥30） |
| **续流二极管 1N4148 或 1N4007** ×5 | 驱动振动马达必须用，清单里没有 | 不用问，直接买（约 ¥2） |
| **万用表** | 全项目最救命的工具 | 你有就不买，没有立刻买 |
| **电源拨动开关** | 现在只能拔线关机，不方便 | 可选（约 ¥5） |
