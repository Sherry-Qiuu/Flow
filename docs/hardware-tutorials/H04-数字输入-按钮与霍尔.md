## 2. GPIO 入门：三分钟看懂

树莓派边上一排 **40 个针脚**，叫 GPIO（General Purpose Input/Output，通用输入输出）。它们能让树莓派"读"外界信号，也能"输出"信号控制别的器件。

### 2.1 三个必须记住的规则

| 规则 | 说明 |
|---|---|
| **只认 3.3V** | 3.3V 进来是"高电平（1）"，0V 是"低电平（0）"。**超过 3.6V 会烧引脚** |
| **每个脚最多 16mA** | 推一个小 LED 可以，推马达绝对不行（H05 讲） |
| **有两种编号** | 物理编号（1–40）和 BCM 编号（GPIO17 这种）。**写代码一律用 BCM** |

### 2.2 本教程用到的引脚（记住这张表）

| 功能 | 物理脚 | BCM | 类型 |
|---|---|---|---|
| 3.3V 电源 | 1 | — | 输出 3.3V |
| 5V 电源 | 2 / 4 | — | 输出 5V |
| GND 地 | 6 / 9 / 14 / 20 / 25 / 30 / 34 / 39 | — | 0V |
| **按钮** | **11** | **GPIO17** | 数字输入 |
| **霍尔 OUT** | **13** | **GPIO27** | 数字输入（需上拉电阻） |
| 振动马达 | 12 | GPIO18 | 数字输出 / PWM |
| 手势 SDA | 3 | GPIO2 | I2C |
| 手势 SCL | 5 | GPIO3 | I2C |

> 在树莓派终端敲 `pinout` 会画出完整的引脚图，做这节的时候一直开着。

### 2.3 什么是"上拉电阻"

开关的一头接 GPIO、一头接 GND。**没按下时，GPIO 是"悬空"的**——它既不是 3.3V 也不是 0V，读数会乱跳（天线效应，会乱收周围电磁噪声）。

上拉电阻就是：**在 GPIO 和 3.3V 之间接一个电阻（通常 10kΩ）**。

```
       3.3V
        │
      [10kΩ]          ← 上拉电阻
        │
        ├────── GPIO ──── 树莓派读取
        │
     [开关]
        │
       GND
```

- 开关**断开**：GPIO 被 10k 拉到 3.3V → 读到 **1**
- 开关**闭合**：GPIO 直接接 GND，电流走开关 → 读到 **0**（因为 10k 很大，只有 0.33mA 流过，安全）

这就是"低电平有效"（active low）—— **按下 = 0**。

**好消息**：树莓派的 GPIO 内部自带可开关的上拉电阻，按钮不需要外部电阻。但霍尔传感器是"开漏输出"，**必须外接** 10kΩ。

## 3. 按钮接线（10 分钟）

### 3.1 认识你的按钮

12mm 自复位金属按钮，通常有 **2 或 4 个针脚**：

- **2 脚**：直接当开关用，不分正负。
- **4 脚**：通常是两两内部短接。同一侧的两个脚是一对，**对角线不通**。用之前用万用表通断档确认一下哪两个是通的。

### 3.2 接线

**断电状态下接线**（很重要，带电插拔容易短路）。

| 按钮脚 | 接到 |
|---|---|
| 脚 1 | 树莓派 **物理 11**（GPIO17） |
| 脚 2 | 树莓派 **物理 9**（GND） |

就这么简单，不需要电阻（用内部上拉）。

> 如果想更保险（防静电），可以在 GPIO17 和按钮之间串一个 **1kΩ** 电阻。不是必须，但新手建议加。

### 3.3 4 脚按钮怎么接

用万用表通断档量：把两个脚配对，**按下时导通的那一对**就是开关的两端。选一对，接法同上，另外两个脚空着即可。

## 4. 霍尔传感器接线（10 分钟）

### 4.1 认识 A3144

A3144 是**开关型霍尔传感器**：检测到磁场（S 极靠近）时，输出从高变低。

三根腿（TO-92 封装，平面朝自己、腿朝下时，从左到右）：

| 腿 | 功能 |
|---|---|
| 左 | VCC（3.3–5V） |
| 中 | GND |
| 右 | OUT（开漏输出） |

> ⚠️ **不同批次的丝印可能不同**。模块上通常有丝印标注（V/G/O 或 3.3/GND/OUT），**以丝印为准**。裸器件就按上面的顺序，接错会烧。

### 4.2 为什么必须加上拉电阻

A3144 是**开漏（open-collector）输出** —— 它只会把输出"拉低到 0V"，**永远不会主动输出高电平**。所以必须外接一个电阻把电平"拉高"，否则读数永远是乱的。

```
      3.3V (物理脚 1)
        │
      [10kΩ]          ← 必须！没有它就测不到
        │
        ├──────── GPI27 (物理脚 13)
        │
   [A3144 OUT]
        │
      [A3144 GND] ──── GND (物理脚 6)
```

### 4.3 完整接线

| A3144 | 接到 |
|---|---|
| VCC（左腿） | 物理 **1**（3.3V） |
| GND（中腿） | 物理 **6**（GND） |
| OUT（右腿） | 物理 **13**（GPIO27） |
| 10kΩ 电阻 | 一端接 **物理 13**，一端接 **物理 1（3.3V）** |

**电阻接法**：电阻是两根腿，直接插在面包板上，跨在 GPIO27 和 3.3V 两排孔之间。

> ⚠️ **不要用 5V 上拉**（物理 2 / 4）。虽然 A3144 本身支持 5V，但 5V 会通过电阻进到 GPIO27，**超过 3.3V 会烧引脚**。只能用 3.3V。

### 4.4 磁铁怎么配合

- A3144 对 **S 极**敏感（多数型号）。磁铁一面吸、一面对它，**翻面试**。
- 有效距离：**5–15 mm**（不同磁铁差别大）。用 D10×3mm 强磁铁可以到 15mm。
- 安装在支架槽背面，手机背面贴一片磁铁，合上时正好对着传感器。

### 5.3 霍尔测试

新建 `~/flow/code/test_hall.py`：

```python
#!/usr/bin/env python3
"""霍尔传感器测试：磁铁靠近/离开，终端打印状态。"""
from gpiozero import DigitalInputDevice
from signal import pause

HALL_PIN = 27         # BCM 编号，对应物理脚 13

# 注意：必须用 pull_up=True，因为 A3144 是开漏输出
hall = DigitalInputDevice(HALL_PIN, pull_up=True, bounce_time=0.05)

def on_change():
    # value == 0 表示检测到磁场（低电平有效）
    if hall.value == 0:
        print("检测到磁铁  →  手机已放上")
    else:
        print("磁场消失    →  手机已拿走")

hall.when_activated   = on_change      # 0V 时触发
hall.when_deactivated = on_change      # 3.3V 时触发

print("当前状态：", "有磁场" if hall.value == 0 else "无磁场")
print("拿磁铁靠近传感器…… Ctrl+C 退出")
pause()
```

> **注意**：代码里也开了内部上拉。如果外部 10k 电阻已经接了，两个上拉并联是没问题的（等效电阻变小，更稳）。如果**没接外部电阻**，内部上拉可能拉不动开漏输出，读数会飘 —— 所以外部 10k 还是建议接。

### 5.4 一次测两个：合并脚本

这套代码后面要直接搬给软件侧的 HAL，写成这个结构：

`~/flow/code/inputs.py`：

```python
#!/usr/bin/env python3
"""心流 FLOW · 数字输入模块（可直接给 HAL 用）"""
from gpiozero import Button, DigitalInputDevice


class ButtonInput:
    """金属 STOP 按钮"""
    def __init__(self, pin: int = 17):
        self._dev = Button(pin, pull_up=True, bounce_time=0.05)

    @property
    def pressed(self) -> bool:
        return self._dev.is_pressed

    def on_press(self, cb):
        self._dev.when_pressed = cb

    def close(self):
        self._dev.close()


class PhonePresence:
    """手机在位检测（霍尔）"""
    def __init__(self, pin: int = 27):
        self._dev = DigitalInputDevice(pin, pull_up=True, bounce_time=0.05)

    @property
    def present(self) -> bool:
        """低电平 = 有磁场 = 手机在架上"""
        return self._dev.value == 0

    def on_change(self, cb):
        self._dev.when_activated = cb
        self._dev.when_deactivated = cb

    def close(self):
        self._dev.close()


if __name__ == "__main__":
    import time
    from signal import pause

    btn = ButtonInput()
    hall = PhonePresence()

    btn.on_press(lambda: print("[按钮] 按下"))
    hall.on_change(lambda: print("[霍尔] 手机在位:", hall.present))

    print("初始状态 —— 手机在位:", hall.present)
    pause()
```

## 7. 排错

### 按钮

| 现象 | 原因 | 处理 |
|---|---|---|
| 完全没反应 | 接到 5V 了 / 接触不良 | 量 GPIO17 对 GND 电压：按下应变 0V |
| 一直显示按下 | 内部上拉没开 | 代码里 `pull_up=True` |
| 按一次触发了 3 次 | 机械抖动 | `bounce_time=0.1` 或加 0.1µF 电容 |
| 4 脚按钮没反应 | 选错了脚位 | 用通断档找导通的那一对 |
| 一按树莓派就重启 | 按钮接到了 5V 或 GND 接到 5V | 立刻断电，重新核对接线 |

### 霍尔

| 现象 | 原因 | 处理 |
|---|---|---|
| 一直是 1（无反应） | 忘接 10k 上拉电阻 | 补上 |
| 一直是 1，但上拉接了 | 磁铁极性反了 | 把磁铁翻个面 |
| 一直是 1，翻面也不行 | 距离太远 | 磁铁贴着传感器 5mm 内测 |
| 一直是 0 | VCC/GND 接反 / 传感器坏了 | 量 VCC 脚对 GND 有没有 3.3V |
| 读数乱跳 | 没接上拉 + 长线天线效应 | 加 10k，线缩短到 20cm 内 |
| 靠近才 0，稍微一动就 1 | 磁铁太小（D3×3 就是这个问题） | 换 D10×3 |
