## 1. 五条绝对红线

违反其中任何一条，**立刻停手，找老师或队友一起看**。

### 🔴 红线 1：锂电池正负极接反

- **后果**：电池保护板失效 / 电池炸裂 / 起火。12V 3S 锂电池组的短路电流能达到几十安培。
- **怎么防**：
  - 接线前用万用表**确认极性**，红线=正、黑线=负。
  - 接线时**只接一根，接完用胶带包好再接另一根**。
  - DC 母座：**中心针 = 正极**（这是工业标准，别自己改）。

### 🔴 红线 2：上电前不测短路

- **后果**：一通电就把树莓派烧了，¥600 没了。
- **怎么防**：每次上电前，万用表打**蜂鸣档**，量 5V 对 GND。
  - **响 = 短路 = 不许上电。**
  - 不响 = 可以做下一步。
- 这个动作只要 10 秒，请做 100 次。

### 🔴 红线 3：5V 进 GPIO

- **后果**：烧掉引脚 → 烧掉 SoC → 整板报废。树莓派 GPIO 只认 3.3V。
- **怎么防**：
  - 上拉电阻**只能接 3.3V**（物理脚 1 或 17），绝不接 5V（脚 2/4）。
  - 接任何外部模块前，**先量它输出的信号电压**。
  - 不确定的模块，先串一个 1kΩ 电阻再接到 GPIO。

### 🔴 红线 4：感性负载直连 GPIO

- **后果**：马达/继电器断电瞬间产生几十伏反电动势，击穿 GPIO 或整板。
- **怎么防**：
  - 马达、继电器、电磁阀、喇叭 —— **全部必须经三极管/MOS 驱动**。
  - 全部必须加**续流二极管**。
  - 不加二极管，你就等着某天开机不亮。

### 🔴 红线 5：无线充电线圈旁有金属/电池

- **后果**：磁场在金属里产生涡流 → 局部高温 → 电池鼓包 → 起火。
- **怎么防**：
  - **没装隔磁片，绝对不通电。**
  - 线圈背面 5mm 内不能有电池、金属件、螺丝。
  - 通电后 30 秒摸一下背板，明显烫就立刻断电。

## 2. 锂电池专项

| 行为 | 能不能做 | 说明 |
|---|---|---|
| 用原配 12V 充电器充电 | ✅ | 只用原配 |
| 用 19V 笔记本电源充电 | ❌❌ | **接口一样大，插错就完蛋**。建议把母座换成 5.5×2.5 或贴警示标 |
| 边充边用 | ⚠️ | 不推荐。发热、加速老化 |
| 充电时人离开 | ❌ | 第一天充电要盯着 |
| 电池完全放电（<10V） | ❌ | 过放会永久损坏 |
| 刺穿、挤压、摔 | ❌❌ | 立刻报废并移到室外 |
| 电池鼓包后继续用 | ❌❌ | 报废，当危险废物处理 |
| 把电池塞进 15×15×5 的盒子里硬挤 | ❌ | 要留 3–5mm 缓冲，不能受力 |
| 电池长期存放（>1 个月） | ⚠️ | 充到 50% 存放，每 2 个月补一次电 |

**电池起火怎么办**：不要用水。用**干粉灭火器**或**大量沙子**覆盖，然后撤离并报警。锂电池会复燃。

## 3. 静电（ESD）

北方冬天、化纤地毯、毛衣 —— 人体静电可达几千伏，足以击穿芯片。

| 场景 | 做法 |
|---|---|
| 拿树莓派/摄像头/传感器 | 先摸一下**接地的金属**（比如金属桌腿）放电 |
| 拿芯片/裸板 | 捏**边缘**，不碰引脚和元件 |
| 存放 | 用防静电袋（原包装袋就是） |
| 冬天开空调的房间 | 更容易静电，动作慢一点 |

> 不会立刻坏，但会"半死"—— 表现出来就是"时好时坏"、"莫名其妙重启"。这类故障最难查。

## 4. 用电与工具安全

| 项 | 注意 |
|---|---|
| 万用表测电流 | **必须串联**，且先确认表笔插在 10A 档对应的插孔，否则会烧表 |
| 万用表测电压 | 并联，先选高档位再往下调 |
| 电烙铁（如果要用） | 300–350°C，用完立刻放回架；不要在无人看管时通电 |
| 焊接时 | 通风；不要烫到电源线皮 |
| 剪线 | 剪之前确认**没通电** |
| 螺丝刀 | 别用金属杆捅进通电的板子 |

## 5. 装配安全的 5 个细节

1. **壳里不能有金属碎屑。** 打孔后要吹干净再加内部元件，否则螺丝屑会短路。
2. **走线不能压在铰链转轴上。** 开合 100 次后一定会断。
3. **螺丝不要拧太紧。** M2 螺丝拧在塑料里，超过 0.3 N·m 就滑丝了。手感"刚好停住"就好。
4. **电池不要贴着散热片/树莓派。** 会互相加热。
5. **合壳前摇一摇。** 听到声音就拆开找 —— 一颗螺丝在壳里晃，早晚短路。

## 6. 演示现场的安全

| 场景 | 风险 | 做法 |
|---|---|---|
| 长时间演示 | 电池耗尽、过热 | 接墙插，不要靠电池 |
| 观众摸设备 | 碰倒、扯断排线 | 放在稳固台面，线用胶带固定在桌面 |
| 手机放上支架 | 磁铁吸不稳掉落 | 提前用真机测试吸力 |
| 无线充电演示 | 发热 | 演示 30 秒就关掉 |
| 设备倒扣/倾斜 | 电池位移 | 电池大面 VHB 固定 |
| 运输过程 | 排线震松 | 装箱时用泡棉填满空隙 |

## 7. 危险动作黑名单（看到就制止）

以下动作**任何人做都要当场喊停**：

- ❌ 带电插拔摄像头/屏幕排线
- ❌ 带电接线（杜邦线、电源线）
- ❌ 用嘴咬电线剥皮
- ❌ 用金属镊子同时碰两个相邻引脚
- ❌ 把 19V 笔记本电源插到 12V 母座上
- ❌ 在充电时拆机
- ❌ 用打火机/热风枪给锂电池加热缩管
- ❌ 电池鼓包了还试着"压平继续用"
- ❌ 无线充通电时把手机以外的金属物放上去
- ❌ 通电时用手直接摸树莓派背面元件

## 8. 出事时的处理顺序

```
1. 断电源        ← 第一优先，拔电池线 / 拔墙插
2. 远离火源      ← 电池起火时，撤离并报警
3. 不要用手拿    ← 发烫/冒烟的电池别用手碰
4. 记录现象      ← 拍张照，后面才知道哪里错了
5. 通知队友      ← 别一个人扛
6. 复盘          ← 写进 B-故障排查手册的记录表
```

**人受伤了先处理人，设备可以再买。**

## 9. 开工前的一句话

> 这套东西里，**唯一可能真正伤到人的是那块 12V 锂电池**。
> 其余所有操作，最坏的结果是烧掉一两百块钱的零件。
>
> 所以：**接电池时慢一点、多量一次、别嫌麻烦。** 其他时候可以大胆试。
