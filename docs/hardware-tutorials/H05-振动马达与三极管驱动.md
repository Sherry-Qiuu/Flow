## 2. 为什么不能直接接 GPIO（必读）

`1027` 是扁平**线性马达（LRA）**，额定 **3V / 约 70–90mA**。

而树莓派 GPIO：

- 单个引脚最大 **16mA**
- 全部引脚合计建议不超过 **50mA**

**90mA 是 16mA 的 5 倍多。** 直连的后果：

1. 引脚内部驱动管过热 → **该引脚永久失效**（这还算好的）
2. 电流灌进 SoC → **整块板子报废**

所以必须用**三极管做开关**：GPIO 只出一丁点电流（约 1mA）去"命令"三极管，由三极管去承担 90mA。

```
                    3.3V ──┬──────────────┐
                           │              │
                        [马达]        [续流二极管]  ← 反向并联！
                           │              │
   GPIO18 ──[1kΩ]── 三极管 B              │
                      │  C ───────────────┘
                      │
                     GND (E)
```

---

## 3. 认识 S8050 三极管

TO-92 封装，三根腿：**E（发射极）、B（基极）、C（集电极）**。

**标准的腿序**（平面朝自己、腿朝下，从左到右）通常是 **E–B–C**。

> ⚠️ **不同厂家的 S8050 腿序可能不同（有 C–B–E 的）**。**一定要先测**，接错会烧三极管或让电路不工作。

### 3.1 用万用表确认腿序（2 分钟，必做）

万用表打到**二极管档**（有 → 符号那档）：

1. 假设中间的腿是 **B**。
2. 红笔接 B，黑笔依次碰另外两根腿。
3. **两根都有 0.6–0.75V 读数** → 中间确实是 B，且是 NPN。这个假设成立。
4. 剩下两根：**读数略小的那个通常是 C**（集电极），另一个是 E。

如果红笔接中间、黑笔碰另外两根**都没有读数**，把表笔反过来再试；如果反接有读数，那说明是 PNP（不是 S8050，换一个）。

### 3.2 怎么插

三根腿插在面包板上，**三根腿分在三个不同的孔行**，不要跨在同一行（会短路）。

---

## 4. 续流二极管：清单里没有，必须补

马达是**感性负载**。断电瞬间，线圈会产生一个反向高压尖峰（可达几十伏）。这个尖峰会把三极管击穿。

解决办法：**在马达两端反向并联一个二极管**，给尖峰提供一条泄放回路。

| 零件 | 型号 | 数量 |
|---|---|---|
| 二极管 | **1N4148**（小信号）或 **1N4007**（整流） | 1–5 只 |

**这是 H01 里标【必买】的那一项**。¥2 的东西，没有它你的三极管活不过一天。

> 二极管有方向！**带白/银环的一端是阴极（K）**，接 **3.3V 侧**；另一端（阳极 A）接 **三极管集电极侧**。

---

## 5. 完整接线表

| 元件 | 一脚接到 | 另一脚接到 |
|---|---|---|
| **1kΩ 电阻** | 物理脚 **12**（GPIO18） | 三极管 **B**（基极） |
| **三极管 S8050** | E（发射极）→ 物理脚 **14**（GND） | C（集电极）→ 马达的一端 |
| **振动马达** | 一端 → 三极管 **C** | 另一端 → 物理脚 **1**（3.3V） |
| **1N4148 二极管** | 阳极 A（无环）→ 三极管 C 侧 | 阴极 K（有环）→ 3.3V 侧 |

**用面包板画的接线（从左到右）**：

```
面包板第 1 列：3.3V  ← 树莓派物理脚 1
面包板第 2 列：马达 正极
面包板第 3 列：马达 负极 + 三极管 C + 二极管 A（无环端）
面包板第 4 列：三极管 B + 1kΩ 电阻一端
面包板第 5 列：三极管 E → GND
面包板第 8 列：3.3V  ← 二极管 K（有环端）
```

> 面包板上的"列"是指**同一排 5 个孔横向连通**。插错一排等于没接，这是新手最常见的错误。

## 6. 写代码（15 分钟）

`~/flow/code/vibrate.py`：

```python
#!/usr/bin/env python3
"""振动马达驱动：支持开关与强度控制。"""
import time
from gpiozero import DigitalOutputDevice, PWMOutputDevice


class VibrationMotor:
    """1027 振动马达，经 S8050 驱动。
    注意：DC 驱动 LRA 只有较弱振动；用 100-200Hz PWM 效果最好。
    """

    def __init__(self, pin: int = 18):
        # 用 PWM 而不是普通输出，才能控强度
        self._pwm = PWMOutputDevice(pin, frequency=150, initial_value=0)

    def on(self, strength: float = 1.0):
        """strength: 0.0 ~ 1.0"""
        self._pwm.value = max(0.0, min(1.0, strength))

    def off(self):
        self._pwm.value = 0

    def pulse(self, seconds: float = 0.15, strength: float = 1.0):
        """震动一小下，然后自动停"""
        self.on(strength)
        time.sleep(seconds)
        self.off()

    def pattern(self, beats=3, on_s=0.1, off_s=0.1):
        """震几下，做"完成提示"用"""
        for _ in range(beats):
            self.on(1.0)
            time.sleep(on_s)
            self.off()
            time.sleep(off_s)

    def close(self):
        self._pwm.close()


if __name__ == "__main__":
    motor = VibrationMotor()
    try:
        print("1. 单次震动")
        motor.pulse(0.3)
        time.sleep(1)

        print("2. 强弱对比")
        for s in (0.3, 0.6, 1.0):
            print(f"   强度 {s}")
            motor.on(s)
            time.sleep(0.5)
        motor.off()

        print("3. 三段提示（任务完成效果）")
        motor.pattern(beats=3)
    finally:
        motor.off()
        motor.close()
        print("结束")
```

运行：

```bash
cd ~/flow/code
python3 vibrate.py
```

## 7. 验证清单

- [ ] 震动明显能摸到（不是嗡嗡的弱电流声）
- [ ] 强度 0.3 / 0.6 / 1.0 有可感知的差别
- [ ] 连续震动 3 秒后三极管**不烫手**（烫 = 基极电阻太小或没饱和）
- [ ] 震动时树莓派**不重启**（重启 = 没有续流二极管，反电动势打穿了电源）
- [ ] 程序退出后马达完全停止
- [ ] 万用表量 GPIO18：静止 0V，震动时约 0.6–1.6V（PWM 平均值）

## 8. 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| 完全不震 | 三极管腿序错了 | 用万用表重测 E/B/C |
| 完全不震 | 三极管插错行（脚没连通） | 每根腿放不同排 |
| 完全不震 | 马达两根线断了（1027 的线极细） | 用万用表测马达两端通断 |
| 一直震不停 | 基极悬空，被噪声触发 | 确认 1kΩ 接好，GPIO18 有下拉 |
| 震动很弱 | 3.3V 供电不足 / 占空比太低 | 提高到 0.8 以上；可改用 5V 供马达（要重新算电阻） |
| **一震动树莓派就重启** | **没有续流二极管** | 立刻断电，补二极管 |
| 三极管发烫 | 基极电流不够，没进饱和区 | 把 1kΩ 换成 470Ω |
| 震一下就停 | 电机堵转 / 卡住 | 检查是不是被胶粘住、被外壳挤住 |

## 9. 提升：LRA 用 PWM 才好

`1027` 是**线性马达（LRA）**，它的最佳驱动方式是 **100–200Hz 的方波**，而不是纯直流。代码里已经设成 `frequency=150`，你可以试试 100 / 150 / 200 哪个震感最舒服。

> 如果换成同规格的转子马达（ERM），纯直流就能正常震，频率反而无所谓。
