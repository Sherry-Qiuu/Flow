# H09 · 显示屏、支架与外壳装配

> **时长** 150 分钟　**难度** ★★★★　**前置** H03、H07
> 这一节没有新电路，只有结构。但**结构做砸了，前面所有电路都会跟着坏**（压断排线、挤坏屏、短路）。

---

## 1. 这一节做完你会得到什么

- 屏幕能显示画面、触摸能用
- 屏幕固定在前面板，不开不晃不压
- 手机支架能开合、能吸附、能检测
- 一台"看起来像个产品"的设备

---

## 2. ⚠️ 先解决一个问题：外壳本体清单里没有

采购清单里有**硅胶包边、VHB 胶、铰链、铜柱、螺丝、磁铁**，但**没有外壳本体**。

你需要自己解决外壳。三个方案：

| 方案 | 时间 | 成本 | 效果 | 建议 |
|---|---|---|---|---|
| **A · 3D 打印（推荐）** | 8–15 小时打印 | ¥30–80 耗材 | 最好，可精确开孔 | 学校创客空间/实验室一般有打印机 |
| **B · 亚克力激光切割 + 拼装** | 2–3 小时 | ¥50–120 | 好，但边缘需要拼接 | 激光切割店可直接下单 |
| **C · 成品塑料盒改造** | 3 小时 | ¥20–40 | 一般，难做准开孔 | 时间紧张时的兜底 |

> 下面所有尺寸按 **方案 A/B** 写。如果选 C，把开孔尺寸按实际盒子调整。

## 3. 关键尺寸（照着设计，不要改）

| 参数 | 数值 | 来源 |
|---|---|---|
| 外形 | **15 × 15 × 5 cm** | 产品文档 P37–P38 |
| 壁厚 | **1.5 mm** | 必须匹配硅胶包边条（卡 1.5mm） |
| 屏幕可视区 | **14 × 14 cm** | 产品文档 P39 |
| 屏幕开窗 | **13.8 × 13.8 cm**（比可视区小 2mm，做压边） | 经验值 |
| 屏幕后方净空 | ≥ **10 mm** | 铜柱要换成 M2.5×4+**10** |
| 摄像头孔 | **Ø8–10 mm**，位于前面板上方居中 | — |
| 手势传感器窗 | **≥ 8 × 8 mm**，位于屏幕上方 | — |
| DC 充电口 | 按母座实际外径开孔（通常 Ø11–12 mm） | — |

### 3.1 为什么壁厚必须是 1.5mm

你买的硅胶包边条是 **U 型、卡 1.5mm 壁厚**的。壁厚 2mm 就卡不进去，壁厚 1mm 会松掉。

> 如果你的打印件公差大，实测壁厚在 1.5–1.7mm 都能卡住，2mm 一定不行。

## 4. 屏幕：先搞清楚它是什么屏

主办方给的"7 英寸触摸显示模组"可能有三类硬件差异，**先确认再接线**：

| 差异点 | 可能是什么 | 怎么确认 |
|---|---|---|
| 视频接口 | **HDMI**（大概率）或 DSI | 看背面接口形状 |
| 触摸接口 | **Micro-USB / Mini-USB / Type-C** 三选一 | 看接口形状，或看说明书 |
| 供电 | 独立 micro-USB / DC 圆口 / 由 HDMI 板供电 | 数一下有几个接口 |

> 你买了 **Mini USB 方口线**，就是为了试触摸口是不是 Mini-USB。**如果是 Micro-USB 或 Type-C，这根线用不上**，需要再买。

### 4.1 接线

典型 7 寸 HDMI 屏的接法：

```
树莓派 micro-HDMI (HDMI0) ──[micro-HDMI 转 HDMI 线]──> 屏幕 HDMI 口（视频）
树莓派 USB-A            ──[USB 线]──────────────> 屏幕 USB 触摸口（触摸 + 可能供电）
树莓派 5V               ──[可选]──────────────> 屏幕 5V 供电口
```

细节：

1. **视频**：Pi 5 用 **micro-HDMI**（不是标准 HDMI），线已经给了。**先接 HDMI0**。
2. **触摸**：屏幕触摸要接到树莓派的 USB 口，系统会把它识别成一个**鼠标设备**（`/dev/input/`）。
3. **供电**：很多 7 寸屏的 USB 口同时承担"供电 + 触摸数据"。如果只接一个口触摸不了，说明要**单独给屏供电**。

> ⚠️ **屏幕非常耗电**（2.5–3.5W）。如果从树莓派 USB 口取电，容易触发树莓派过流保护导致重启。**建议屏幕单独从 5V 轨（H03 的降压模块）取电**。

### 4.2 显示方向与分辨率

```bash
# 看当前分辨率
xrandr

# 如果是桌面版，可以在 设置 → 屏幕 里调
```

如果画面旋转了/上下颠倒，在 `~/.config/labwc/autostart`（Pi 5 Bookworm 用 labwc）或 `raspi-config → Display Options` 里调。

### 4.3 触摸测试

```bash
# 看触摸设备是否被识别
ls /dev/input/
cat /proc/bus/input/devices | grep -A2 -i "touch\|hid"
```

用手指点屏幕，桌面上的鼠标指针跟着动 = 触摸正常。

## 5. 结构装配：按这个顺序（不然装不回去）

> **总原则：从里到外、从下到上、先电后线、最后合壳。**

### 第 1 步：底板打孔（30 分钟）

在底板（15×15cm 那块）上开：

- 树莓派 4 个 **M2.5** 安装孔（间距按 Pi 5 官方尺寸）
- 降压模块 2 个 M2 孔
- 电池用 VHB 粘，不打孔
- 走线孔：至少 2 个 **Ø10mm** 圆孔，用于电源线和排线穿层

> **先打孔，再装任何东西。** 装完再打孔会把碎屑掉进电路里。

### 第 2 步：装铜柱（10 分钟）

用 **M2.5×4+10** 铜柱（⚠️ 不是清单里的 4+6）把树莓派架空 **10mm**。

为什么必须 10mm：树莓派背面有元件（SD 卡座、排线座），6mm 会被前面板的屏幕背板顶住，**顶住 = 短路 = 烧板**。

四个角各一个，用 M2.5 螺母锁紧。

### 第 3 步：装屏幕（30 分钟）

1. 屏幕背面先接好 **HDMI 线、触摸 USB 线、电源线**——**装进壳里就看不见接口了**。
2. 屏幕放进前面板开窗处。
3. 用 **VHB 双面胶**沿屏幕四边粘到前面板**内侧**。
   - 先贴胶条，再把屏幕压上去，压 30 秒。
   - **不要用热熔胶**（温度高会软化，屏幕会掉）。
4. 屏幕和开窗之间**不能有缝**（会进灰、会漏光）。

> ⚠️ 屏幕排线/软板在背面，粘的时候**不要压在软板上**，会把排线压断。

### 第 4 步：装摄像头与手势传感器（20 分钟）

- 摄像头：对准 Ø8–10mm 孔，VHB 固定，镜头面离面板 1–2mm。
- 手势传感器：对准 ≥8×8mm 窗口，传感器正面朝外，**窗口范围内不能有金属**。

### 第 5 步：装电池与电源模块（20 分钟）

1. 电池用 **VHB 大面积粘**在底板上（不能只用一小条，电池会掉）。
2. **电池和无线充线圈之间必须 ≥5mm**（H08）。
3. 电池不要贴着树莓派（散热）。
4. 降压模块用 M2 螺丝固定在底板。
5. **所有走线用扎带或胶带固定**，不要让线悬在中间。

### 第 6 步：装支架与铰链（30 分钟）

```
        ┌──────────────┐
        │              │  ← 手机吸附面（贴磁铁 + 无线充线圈在背面）
        │   支架面板    │
        └──┬────────┬──┘
           │        │
        [铰链]   [铰链]      ← 阻尼铰链 8kgf·cm，一对
           │        │
        ┌──┴────────┴──┐
        │   机身背面    │
        └──────────────┘
```

1. 铰链用 **M2×10 螺丝**固定在机身背面和支架面板。
2. **铰链必须装在同一条轴线上**，否则会卡死、会把塑料拉裂。
3. 调阻尼：铰链上有调节螺丝，拧紧到"能停在任意角度"。
4. 磁铁用 VHB 粘：手机上的一片、支架上的一片，**极性要相吸**（装之前先试）。
5. **磁铁离无线充线圈中心 ≥30mm**（H08）。

> ⚠️ 铰链拧螺丝时**不要一次拧死**，四个螺丝交替慢慢上，让受力均匀。

### 第 7 步：硅胶包边（15 分钟）

沿外壳边缘按压硅胶 U 型条。

- 从一个角开始，**顺着边推**，不要拉（拉了会变细、卡不住）。
- 四个角剪 **90° V 型口**再弯，能贴合得漂亮。
- 收尾处留 2mm 重叠，用一点热熔胶固定端头。

### 第 8 步：合壳（20 分钟）

**合壳前的最后检查（照着念一遍）：**

- [ ] 所有排线都插好、卡扣压紧
- [ ] 所有线都不在合缝处（合上会被压断）
- [ ] 万用表量 5V 对 GND **不短路**
- [ ] 电池极性正确
- [ ] 没有螺丝、垫片掉在壳里（**摇一摇听声音**）

然后上螺丝 / VHB 粘合，先 **半紧**，试一次开机，没问题再全紧。

## 6. 验证清单

- [ ] 屏幕能正常显示，分辨率正确
- [ ] 触摸能响应，指针跟手
- [ ] 摄像头能拍照（装壳后）
- [ ] 手势传感器能识别（装壳后）
- [ ] 按钮可用
- [ ] 霍尔能检测到手机
- [ ] 支架开合顺畅，能停在任意角度
- [ ] 磁铁吸力足够，手机会"啪"一下吸附
- [ ] 硅胶包边平整，没有翘边
- [ ] 摇一摇，壳内没有异响
- [ ] 连续开合支架 10 次，排线没松
- [ ] 整机重量可接受（目标 < 800g）

## 7. 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| 屏幕黑屏 | 接的是 HDMI1 | 换 HDMI0 口 |
| 屏幕黑屏 | 屏幕没上电 | 单独给屏供电 |
| 屏幕有条纹/闪烁 | 排线接触不良 / 线太长 | 换短线，重新插 |
| 触摸不工作 | 触摸线没接 / 接错口 | 试 Mini/Micro/Type-C 三种线 |
| 触摸位置偏移 | 触摸和显示没对齐 | 用 `xinput` 校准，或换屏幕方向 |
| 装壳后树莓派重启 | 铜柱太矮，Pi 背面顶到屏背板短路 | **立刻拆开**，换 4+10 铜柱 |
| 装壳后摄像头失效 | 排线被压断 / 被铰链夹住 | 拆开检查排线 |
| 支架开合卡顿 | 两个铰链不同轴 | 重新定位 |
| 支架合不上 | 磁铁太小（D3×3） | 换 D10×3 |
| 屏幕有压痕/亮斑 | 装配时压到了 | 无法修复，只能换屏（小心！） |
| 硅胶包边翘边 | 壁厚不匹配 | 打磨或加胶 |
| 整机发烫 | 散热没装好 / 壳内不通风 | 开通风孔，检查风扇 |
