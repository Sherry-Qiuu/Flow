# H03 · 电源系统：12V 电池 → 降压模块 → 树莓派 5

> **时长** 120 分钟　**难度** ★★★★　**前置** H02
> **这是整套教程里最容易烧板、也最容易起火的一节。** 请从头读到尾再动手。

---

## 1. 这一节做完你会得到什么

- 一块脱离墙插、靠 12V 锂电池供电的树莓派 5
- 机身上的 DC 充电口（可以给电池充电）
- 一份实测的功耗与续航数据（后面软件做降级策略要用）

---

## 2. 先搞懂原理（3 分钟）

```
  [12V 锂电池组]
        │  12V, 2800mAh
        ▼
  [DC5.5×2.1 母座]──────── 外接 12V 充电器（充电时走这条路）
        │
        │  12V
        ▼
  [DC-DC 降压模块]  12V→5V, 最大 5A (25W)
        │  5V, Type-C 母座
        ▼
  [树莓派 5]  Type-C 母座  ← 用 C-to-C 短线连起来
```

**为什么不能直接给树莓派接 12V？**
树莓派 5 的输入电压是 **5V**。12V 直接进去 = 瞬间烧毁，没有任何挽救余地。

**为什么需要 5A？**
树莓派 5 峰值能吃掉 5V/5A（25W）。降压模块标称 5A 是刚好够用，**没有余量**。所以：

- 屏幕、音箱、无线充电这些**不要全都从这一路取电**，否则高负载时会掉压重启。
- 真正装机时建议给屏幕单独一路（见 H09）。

## 3. 功耗与续航，先算清楚（很重要）

| 负载 | 待机功耗 | 高负载功耗 |
|---|---|---|
| 树莓派 5 | 3.5 W | 10 W |
| 7 寸屏 | 2.5 W | 3.5 W |
| USB 音箱 | 0.5 W | 2 W |
| USB 麦克风 | 0.5 W | 0.5 W |
| 摄像头 | 0.2 W | 0.5 W |
| 手势/霍尔/马达 | 0.1 W | 0.5 W |
| **无线充电（给手机）** | 0 W | **7 W（输入）** |
| **合计** | **≈ 7.3 W** | **≈ 24 W** |

12V 2800mAh 电池 ≈ **33.6 Wh**，降压效率按 87% 算：

| 场景 | 实际续航 |
|---|---|
| 待机（只显示表情） | **≈ 4 小时** |
| 正常使用（屏亮 + 语音 + 摄像头偶尔用） | **≈ 2.5 小时** |
| 一边用一边给手机无线充电 | **≈ 1.2 小时** ⚠️ |
| 满负载（大屏 + 音箱 + 充电） | **< 1 小时** ⚠️ |

> **结论：用电池供电时，关掉无线充电。** 手机要充电时插墙插。这个取舍要写进产品说明，不然演示到一半没电会很尴尬。

## 5. 步骤

### 第 0 步：测电池（2 分钟，别跳）

万用表打**直流电压档 20V**，红笔接红线、黑笔接黑线：

| 读数 | 含义 | 处理 |
|---|---|---|
| 12.4–12.6 V | 满电 | ✅ 可以开始 |
| 11.5–12.3 V | 用了不少 | 可以继续，但续航会短 |
| **10.5–11.4 V** | 亏电 | **先充电再用** |
| **< 10 V** | 过放 | 电池可能已损坏，**不要用**，换货 |
| 负数 | 表笔接反了 | 调换表笔 |

**顺便确认极性**：红线是正（+），黑线是负（−）。如果不确定，用万用表确认后再接线 —— **这一步搞错会烧一切**。

### 第 1 步：确认降压模块的输出电压（5 分钟，必做）

**在接树莓派之前，先单独测模块。**

1. 用 DC 公头线把电池接到模块的**输入端子**（标 `IN+` / `IN-`，注意正负）。
2. 万用表打直流 20V，红笔插模块 Type-C 的 **VBUS**（最外侧两个脚），黑笔接 **GND**。
   > 没有 Type-C 测试夹的话：把 C-to-C 线插进模块，**量线的另一头**。
3. 读数应该是 **5.0–5.2 V**。

| 读数 | 处理 |
|---|---|
| 4.9–5.2 V | ✅ 正常，继续 |
| 5.3–6 V | 模块可能默认输出偏高，看有没有电位器调到 5.1V |
| 12 V 左右 | **模块没工作 / 是直通模块**，别接树莓派 |
| 0 V | 输入没接好 / 模块坏 |

> 有些降压模块是**固定 5V 无电位器**，那就不用调。有电位器的话，用螺丝刀慢慢转，看着表调到 5.1V。

### 第 2 步：在树莓派上开启 5A 模式（10 分钟）

树莓派 5 有一个"防呆"机制：**如果不是官方 PD 电源，它会自动限制到 3A**（USB 外设只能用 600mA）。电池方案不是 PD 协议，所以必须手动告诉它。

SSH 进去：

```bash
sudo nano /boot/firmware/config.txt
```

在文件末尾（`[all]` 段落下）加一行：

```
usb_max_current_enable=1
```

`Ctrl+O` 保存、回车、`Ctrl+X` 退出，然后：

```bash
sudo reboot
```

**验证是否生效**：

```bash
vcgencmd get_config usb_max_current_enable
# 应该返回：usb_max_current_enable=1
```

> 不加这一行的后果：树莓派能开机，但插上音箱/麦克风/摄像头后会掉电重启、USB 设备时有时无，而且你会以为是软件问题查半天。

### 第 3 步：第一次用电池供电（10 分钟）

1. **先拔掉 PD 墙插**。
2. 把 C-to-C 短线一头插降压模块、一头插树莓派 5。
3. 观察树莓派：红灯亮、绿灯闪 = 正常启动。

**上电后立刻做两件事：**

```bash
# 看一眼有没有欠压
vcgencmd get_throttled
```

返回 `throttled=0x0` = 完美，没有任何欠压记录。

| 返回值 | 含义 |
|---|---|
| `0x0` | ✅ 正常 |
| `0x50000` | 曾经欠压过（历史记录） |
| `0x50005` | **当前就在欠压**，立刻断电检查 |
| `0x1` / `0x50001` | 现在欠压 + 已降频 |

```bash
# 看实际输入电压（Pi 5 支持）
vcgencmd pmic_read_adc EXT5V_V
```

读数应 ≥ **4.85 V**。低于 4.8V 说明线太细或模块撑不住 → 换更粗的 C-to-C 线。

### 第 4 步：做机身充电口（30 分钟）

DC 母座装在机壳上，用来接 12V 充电器。

**接线方案（免焊，用 KF301 端子）**：

```
[DC 母座] 中心针 (+) ──┐
                        ├──> KF301 端子 ──> 电池充电输入端
[DC 母座] 外壳 (−) ────┘
```

⚠️ **两个关键点**：

1. **中心针 = 正极**（DC5.5×2.1 的标准约定）。接反 = 充电器直接正负反接到电池，非常危险。**接完后用万用表再次确认极性**，再把充电器插上。
2. **充电口和放电口不能同时用同一个口**，除非电池自带"同口充放"的 BMS。看你手上电池：
   - **电池有独立充电口** → 母座接充电口，放电从另一组线出来，最简单。
   - **电池只有一个口（同口）** → 需要加一个**切换开关**（一档充电、一档放电），否则充电器和降压模块会互相打架。

   买之前先看清楚电池有几个接口。

**走线规范**：

- 正极线走红色/贴红标签，负极走黑色。
- 所有裸露的金属接头用**绝缘胶带或热缩管**包住，不能有铜丝外露。
- 电池线从机壳内部走，**不要压在铰链和屏幕排线上**。

### 第 5 步：整机功耗实测（20 分钟）

装好电池后，测三种场景下的电流，填进记录表：

```bash
# 用一个脚本制造负载（在树莓派上跑）
sudo apt install -y stress-ng
stress-ng --cpu 4 --timeout 60s &
```

用万用表**串联**在电池和降压模块之间测电流（打断电路，表串进去，打 10A 档）。

| 场景 | 12V 侧电流 | 折算功率 |
|---|---|---|
| 待机（只有屏亮） | ______ A | ______ W |
| CPU 满载 | ______ A | ______ W |
| 满载 + 音箱播报 | ______ A | ______ W |

> 没有条件串表测电流的话，用 `vcgencmd pmic_read_adc` 读各路电压 + 粗略估算也行，但**至少要做一次串表实测**，你才会对"电池能用多久"有真实概念。

## 7. 排错

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 接上电池完全没反应 | 正负极接反 / 电池没电 | 万用表查极性、查电压 |
| 开机后屏幕右上角出现 **闪电图标** | 欠压 | 换更粗的 C-to-C 线；查 `get_throttled` |
| 用一会儿就重启 | 模块过流保护触发 | 减少同时负载；给屏幕单独供电 |
| USB 设备时有时无 | 没加 `usb_max_current_enable=1` | 回第 2 步 |
| 电池很快就没电 | 无线充电开着 / 电池老化 | 关无线充；测电池容量 |
| 关机后自动又开机 | 没有物理断电开关，Pi 5 处于待机 | 加拨动开关，或习惯用 `sudo shutdown -h now` 后拔线 |
| 充电时设备发热严重 | 边充边用 | **充电时不要用**，等充满 |
| 电池发烫 / 鼓包 | 过充、短路、劣质 BMS | **立刻断电、移到室外、不要再用** |

## 8. 安全红线（这一节专属）

1. 🔴 **接反一次就报废**。每次接新线，先用万用表量，再上电。
2. 🔴 **不要边充边用**。锂电池同时充放会显著发热，缩短寿命，有安全风险。
3. 🔴 **充电时人不要离开**。第一天充电盯着，摸一下电池温度，正常是微温，烫手就停。
4. 🔴 **不要刺穿、挤压、拆解电池**。装在 15×15×5 的盒子里，要留出缓冲空间，不能硬塞。
5. 🔴 **充电器只能用原配的 12V**。不要用 19V 笔记本电源（很多笔记本电源是 19V，接口还一样大，很容易插错）。
   > 建议：把 DC 母座换成 **5.5×2.5mm** 或加一个标贴，避免和笔记本电源混用。
