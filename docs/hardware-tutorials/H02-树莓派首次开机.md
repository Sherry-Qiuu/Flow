# H02 · 树莓派首次开机

> **时长** 90 分钟　**难度** ★★☆　**前置** H01
> **只用主办方的 PD 电源**。电池和降压模块这一节完全不碰。

---

## 1. 这一节做完你会得到什么

- 一块能开机、能连网的树莓派 5
- 能用 SSH 从自己电脑连上去（不用一直插着屏和键鼠）
- 能显示画面到 7 寸屏
- 摄像头、I2C 接口已启用

---

## 2. 需要的东西

| 必须 | 可选但强烈建议 |
|---|---|
| 树莓派 5、5.1V/5A PD 电源、microSD 卡 | USB 键盘鼠标 |
| microSD 读卡器、你自己的电脑 | 显示器（先用普通 HDMI 显示器调通，再接 7 寸屏） |
| 网线 或 已知密码的 WiFi | 一个手机支架（把屏支起来） |

---

## 3. 第 0 步：装散热（必做，10 分钟）

树莓派 5 会到 80°C 以上然后自动降频。**散热不装好，后面所有调试都会莫名其妙变慢。**

1. 撕掉铝合金外壳内部导热贴的保护膜。
2. 把铜散热片贴在标注的芯片上（一般 3 片：主芯片、内存、电源管理芯片）。
   - 位置拿不准就**只贴主芯片那一片**，其他不贴也不会坏。
3. 风扇排线插到板子上的 **4 针风扇接口**（标 `FAN`，在 GPIO 排针旁边）。
4. 把板子装进铝壳，拧好底盖。

> 风扇是 PWM 温控的，开机后温度 60°C 以上才会明显转起来，转得慢是正常的。

---

## 4. 第 1 步：烧录系统（20 分钟）

### 4.1 下载工具

电脑上装 **Raspberry Pi Imager**（官网 raspberrypi.com/software，免费）。

### 4.2 烧录时一定要配置的 5 项

插上 microSD 卡，选：

- **设备**：`Raspberry Pi 5`
- **系统**：`Raspberry Pi OS (64-bit)` —— **选带桌面（Desktop）的版本**，教学阶段方便你看到东西
- **存储**：你的 microSD 卡

然后点**右下角齿轮 ⚙ / "编辑设置"**，这一步千万别跳过：

| 设置项 | 填什么 | 为什么 |
|---|---|---|
| 主机名 | `flow` | 之后能用 `flow.local` 访问，不用记 IP |
| 用户名 / 密码 | `flow` / 你自己设一个**记得住的** | 每次开机都要用 |
| WiFi | 你们宿舍/实验室的 2.4GHz 或 5GHz | 不联网装不了库 |
| 区域设置 | 时区 `Asia/Shanghai`，键盘 `us` | 时间错了提醒功能全废 |
| **启用 SSH** | 勾上，用密码登录 | 这是后面所有远程操作的前提 |

### 4.3 写入

点"写入"，等 5–15 分钟。完成后拔出读卡器，把卡插进树莓派。

---

## 5. 第 2 步：第一次开机（15 分钟）

1. **先接屏，再接电**。用 micro-HDMI 线接树莓派。
   > Pi 5 有两个 micro-HDMI 口，标着 **HDMI0 和 HDMI1**。**先用 HDMI0**（靠近 Type-C 电源口的那一侧）。没画面就换另一个口，这是新手最常卡住的地方。
2. 插网线（如果 WiFi 不稳）。
3. **最后**插 PD 电源。红灯常亮、绿灯闪烁 = 正在启动。
4. **第一次启动要 2–5 分钟**（会重启一次），别以为坏了。
5. 看到桌面就成功了。

### 如果屏幕没画面

| 现象 | 原因 | 处理 |
|---|---|---|
| 绿灯闪几下就停 | SD 卡没插好 / 卡坏了 | 重新插拔，或用 Imager 重新写 |
| 红灯亮绿灯完全不闪 | 电源不够 | 换回官方 PD 电源，别用手机充电器 |
| 有电但没画面 | HDMI 接错口 | 换另一个 micro-HDMI 口 |
| 有电但没画面 | 屏幕没上电 | 7 寸屏要单独供电（见 H09） |
| 屏幕有彩色方块 | 正常启动画面 | 等 2 分钟 |

---

## 6. 第 3 步：更新系统（15 分钟，可以去做别的）

打开终端（桌面上的黑色图标），敲：

```bash
sudo apt update
sudo apt full-upgrade -y
sudo reboot
```

> 这一步会跑很久，期间别断电。跑完重启一次。

---

## 7. 第 4 步：启用需要的接口（10 分钟）

```bash
sudo raspi-config
```

依次进：

1. `Interface Options` → `I2C` → **Yes**（手势传感器要用）
2. `Interface Options` → `SPI` → **Yes**（备用，接传感器可能用到）
3. `Interface Options` → `Serial Port` → 登录 shell 选 **No**、硬件串口选 **Yes**（暂时用不到，先关着）
4. `System Options` → `Boot / Auto Login` → 选 **B4 Desktop Autologin**（开机自动进桌面，后面做一体机用）
5. `Display Options` → `Screen Blanking` → **No**（不然几分钟不动屏就黑了）

**摄像头在 Pi 5 上默认就启用**，不需要再开 `Legacy Camera`（那个选项在 Pi 5 上是无效的，选了反而可能出问题）。

最后 `Finish`，选择重启。

---

## 8. 第 5 步：从电脑远程连上（15 分钟）

这一步做完，你就可以**把树莓派留在桌上，用自己的电脑写代码**。

### 8.1 查到 IP

在树莓派终端：

```bash
hostname -I
```

会输出类似 `192.168.1.37`。记下来。

> 主机名设成了 `flow` 的话，很多网络里可以直接用 `flow.local` 代替 IP。

### 8.2 用 SSH 连

在**你自己的电脑**上（Windows 打开 PowerShell）：

```bash
ssh flow@192.168.1.37
```

第一次会问 `yes/no`，输 `yes`，然后输密码。

### 8.3 传文件（可选）

Windows 上用 **WinSCP** 或 **MobaXterm**，用同样的地址和账号密码，可以拖文件。

> 传代码用 `scp` 也行：
> ```bash
> scp .\test.py flow@192.168.1.37:/home/flow/
> ```

---

## 9. 第 6 步：建工作目录（5 分钟）

```bash
mkdir -p ~/flow/{code,data,logs}
cd ~/flow
```

以后所有脚本都放 `~/flow/code`，拍的照、存的数据放 `~/flow/data`。

---

## 10. 验证：这一节算不算做完

在树莓派终端逐条敲，**每条都要有正常输出**：

```bash
# 1. 看温度（应该在 40-60°C）
vcgencmd measure_temp

# 2. 看 GPIO 引脚图（能看到 40 脚图就对了）
pinout

# 3. 看 I2C 是否启用（应该出现 /dev/i2c-1）
ls /dev/i2c*

# 4. 看摄像头是否被识别
rpicam-hello --list-cameras

# 5. 看系统版本
cat /etc/os-release | head -3
```

**检查清单**

- [ ] 屏幕有画面，能进桌面
- [ ] 能连上网（`ping -c 3 baidu.com` 有回应）
- [ ] 从自己电脑 SSH 能连上
- [ ] `vcgencmd measure_temp` 返回 60°C 以下
- [ ] `pinout` 显示 40 脚图
- [ ] `ls /dev/i2c*` 出现 `/dev/i2c-1`
- [ ] `rpicam-hello --list-cameras` 能看到 `imx219`

---

## 11. 排错

| 现象 | 最可能的原因 | 处理 |
|---|---|---|
| `rpicam-hello: command not found` | 系统版本太老 | 重装 Bookworm 64-bit |
| `--list-cameras` 显示 `No cameras available` | 摄像头排线没插好 / 接反 | 断电重插（见 H07） |
| `ls /dev/i2c*` 没有输出 | I2C 没启用 | 回第 7 步开一下 |
| SSH 连不上 | 不在同一网络 / SSH 没开 | 用网线直连路由器再试 |
| 桌面卡顿严重 | 散热没装 / 电源不足 | 检查风扇排线、换 PD 电源 |
| 屏幕几分钟就黑 | 屏幕保护 | `raspi-config` 关 Screen Blanking |
| 时间不对 | 时区没设 | `sudo timedatectl set-timezone Asia/Shanghai` |
